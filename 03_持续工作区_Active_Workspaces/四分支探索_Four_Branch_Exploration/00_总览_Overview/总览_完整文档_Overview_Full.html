四分支探索——总览与导航

日期：2026-07-08 性质：PhD 研究方向的四个候选深化路径 前置：V4_1 改进提案 → V4_2 缺口补齐版 → 2026-07-07 导师初读汇报

一、为什么需要这轮探索

V4 的发展链条（V4 → V4_1 → V4_2 → V4_3 导师汇报）已经建立了一个相当完备但理论上偏窄的框架：以前景理论为唯一理论锚，以BDM（行为偏差指数）为核心构念，以清算风险增量预测为主判据。盲点自检发现的 Safe 钱包、决策锚、emic 参考点等问题已通过闸门设计得到缓解。

但两个深层张力尚未被正视：

1. V4 把"行为"等同于"偏离理性基准的偏差"——这继承了行为经济学的静态偏见框架，但 DeFi 的可观测性意味着行为可以被更丰富地概念化：不仅仅是"有没有按理性人应该做的去做"，而是"在完整可见的决策环境中，行为人如何随时间演化其风险姿态"。

2. V4 的理论单薄性——前景理论是 1979 年的框架，被反复使用。DeFi 为金融行为研究提供的不应该只是"又一个可以检验既有理论的场景"，而应该是"因为场景的特殊性，它允许我们提出传统金融无法问的问题"。

本轮探索旨在正面应对这两个张力，提出四种不互斥但方向迥异的理论深化路径。

二、四分支概览

Branch A：RAT+BDM 整合——从静态偏差到风险调整轨迹

核心直觉：V4 用 BDM 把行为压缩为五个维度的静态偏差指数，丢失了时间动态。为什么不反过来，把"行为过程"本身作为信用信号？ 与 V4 的关系：继承 BDM 构念和 RQ2 的信用预测问题意识，但用序列分析（optimal matching / DTW / sequence analysis of life course traditions）替代前景理论作为理论锚。 关键词：风险调整轨迹（RAT）、序列分析、多通道行为过程、清算演化分期 适用期刊：计量经济学（Journal of Econometrics）、社会学期刊（Sociological Methodology）、计算社会科学

Branch B：DeFi 决策本体论——透明系统中的信息生产

核心直觉：DeFi 的透明性 =/= 信息对称。透明性意味着所有交易可见，但信用判断需要的是关于未来偿付能力的信号，不是历史行为本身。这不是"信息不对称→市场失灵"的旧问题，而是一个信息生产装置（ontology of credit information）的哲学问题。 与 V4 的关系：彻底换掉前景理论，用信息经济学 / Stiglitz-Weiss 信用配给理论的拓展 + 知识本体（ontology）作为分析框架。 关键词：信用信息本体、信息生产函数、Palantir 式决策知识图谱、Stiglitz & Weiss 信用配给 适用期刊：Accounting Review（信息生产视角）、MIS Quarterly、Organization Science

Branch C：异质预期与演化响应函数

核心直觉：前景理论假设了"普遍的人性常数"（$\lambda > 1$ 对所有人成立），但 DeFi 借款人是异质的。为什么不从理论上把 DeFi 借款人建模为不同类型的行为策略持有者，检验其策略分布和演化动态，并考察不同策略类型是否有差异化的信用后果？ 与 V4 的关系：保留行为偏差与信用后果的连接内核，但放弃"普适前景理论常数"的假设，转而检验行为策略的异质性分布和演化选择。 关键词：异质代理人模型（HAM）、演化稳定策略、行为类型学、策略分布动态 适用期刊：JEDC（Journal of Economic Dynamics and Control）、Quantitative Finance、JBF（Journal of Behavioral Finance）

Branch D：数据驱动最小重写

核心直觉：V4 框架中，前景理论的角色是"提供可证伪预测"。但如果前景理论在 PoC 中被拒绝（例如 $\lambda \leq 1$，或参考点效应不显著），整个 V4 的逻辑链条就断了。为什么不准备一个不依赖任何强行为理论的版本——用纯数据驱动的方法来定义"异常行为"，然后检验异常行为是否预测清算？ 与 V4 的关系：最保守的修正——砍掉所有行为理论假设，只保留"是否存在行为偏差"和"偏差是否有信用预测力"两个实证问题。 关键词：无理论偏见、数据驱动异常检测、ML 基准模型、最小发表单元 适用期刊：This branch is the fallback——如果 A/B/C 的 PoC 全部失败，D 提供最低成本的可发表路径。

三、四个分支的关系

这四个分支不是互斥的选择。它们可以这样理解：

- D 是最小内核：只要 PoC 能证明"DeFi 借贷行为包含信用信息"，论文就能发表 - A 是最自然的方法论升级：把"偏差"改为"轨迹"，不需要更换理论传统，但需要驾驭复杂的时间序列方法 - B 是最原创但最高风险的方向：它要求提出一个全新的理论框架，不是"再用一个既有理论" - C 是最与当前主流行为经济学/金融学对话的方向：它是 HAM（Heterogeneous Agent Models）传统的一组实证拓展，有清晰的期刊路径

我的推荐顺序（如果导师要求先走一条线）：

- A (RAT) 作为主要探索方向——它在方法上最精进，且与 V4 的连续性最强 - B (DeFi 本体论) 作为长期理论框架——它可以成为 PhD 论文的理论"帽子"，不一定要在第一篇实证论文中完成 - C (异质预期) 作为第一篇论文的备选框架——如果前景理论被拒绝 - D (数据驱动) 作为永远的安全网

Branch A：Risk Adjustment Trajectories（RAT）——从行为偏差到行为过程的信用信号

核心直觉：V4 把"行为"压缩为五个 BDM 维度的静态得分，丢失了时间动态。为什么不反过来，把行为过程——借贷、还款、加抵押、撤抵押、切换抵押品——视为一条可被序列分析工具度量的轨迹，把信用判断理解为"这条轨迹的形态包含清算风险信息"？

1. 与 V4 的连续与断裂

连续性

- 继承 V4 的问题意识：DeFi 借贷行为包含超越传统风险指标的信用信号 - 继承 BDM 的构念家族（补救超配度、参考点跳变、抵押品切换方向等） - 继承 RQ2 的赛马设计精神（M0 基线 vs M_BDM 增强模型） - 继承决策锚的福利量化要求（行为信息必须能转化为治理决策）

断裂

- 不再以前景理论为唯一的理论锚。前景理论框架本身是静态的：它预测个体在"那一刻"如何偏离理性基准。但信用判断的核心是时间——借款人在不同市场状态下的演化模式，而不是单一时间截面的偏差幅度。 - BDM 从"构念"变为"轨迹特征"。在 V4 中，BDM 是自变量（预测清算）。在 RAT 中，BDM 维度被时间展开为轨迹，经序列分析降维后再进入预测模型。 - 方法传统从截面/面板回归转向序列分析（sequence analysis），从计量的假设检验传统转向生命历程/社会序列分析的传统（Abbott, 1995; Aisenbrey & Fasang, 2010）。

2. 理论框架

2.1 核心概念

Risk Adjustment Trajectory (RAT)：借款人在 DeFi 借贷协议上，从首次开仓到被清算（或还清/退出）期间，其风险调整行为（加抵押、还款、增贷、撤抵押、抵押品切换）在时间轴上的形态。RAT 是多通道序列（multi-channel sequence），至少包含三个通道：
通道内容状态空间
仓位调整方向加抵押 / 还款 / 增贷 / 撤抵押 / 无行动5 个名义状态
健康因子区间(1.0, 1.1] / (1.1, 1.2] / (1.2, 1.5] / (1.5, 2.0] / >2.05 个有序区间
抵押品风险态度增加波动资产 / 增加稳定币 / 无变化3 个名义状态

三通道同时分析（multi-channel optimal matching），比单通道序列分析能捕获更多信息。

2.2 关键理论创新：从"偏差"到"轨迹"

V4 中的 BDM 隐含假设是存在一个理性基准：借款人"应该"在 HF 下降时加抵押，"应该"在危险时避免切换波动资产。但序列分析传统认为，行为的意义不在于偏离基准的幅度，而在于整个序列形态与社会类型学中的位置。

类比： - 生命历程研究不问你偏离了"标准人生轨迹"多少，而是问你属于"早婚-早育-高就业"还是"晚婚-无子-创业"类型 - 序列分析不预设一个"正确"的轨迹，它通过最优匹配（optimal matching）或动态时间规整（DTW）来度量序列之间的形态相似度，然后做聚类

2.3 理论来源

1. 社会序列分析 (Abbott, 1995; Aisenbrey & Fasang, 2010)：最优匹配、序列距离、序列聚类、差异分解。此文献传统提供了处理分类状态序列的核心方法工具。

2. 生命历程研究 (Elder, 1998; Mayer, 2009)：人生轨迹（trajectory）与转折（turning point）的概念区分为 DeFi "开仓→还清→再开仓"提供了理论类比。

3. 犯罪学中的发展轨迹 (Nagin, 2005; Piquero, 2008)：群体基础的轨迹建模（Group-Based Trajectory Modeling, GBTM）识别"慢性犯罪者""青春期限定型"等类型——这与"高风险清算型""临时加杠杆型""稳健还款型"的类比不言而喻。

4. 高管薪酬/公司财务中的行为序列 (Stuart & Yim, 2010; Shi, Zhang & Helfat, 2017)：虽然具体领域不同，但将管理者决策展开为序列形态、考察序列特征如何预测组织结果的逻辑可直接移植。

5. 金融中的动态时间规整 (DTW)：Bai et al. (2019) 已将 DTW 应用于动态金融网络的相似度度量——证明金融领域的序列分析不缺乏计算工具。

3. 操作化方案

3.1 分析单元：用户-开仓周期（user-spell）

每个"开仓→还清/清算"是一个分析单元（spell），而非用户-月。这将研究从面板数据转换为序列数据： - 每个 spell 的多通道状态序列作为行 - 序列长度用 month 或 week 对齐（DTW 可处理不等长序列） - 结局变量：spell 以"清算"结束（1）还是"正常还清/进行中"结束（0）

3.2 核心流程

第一步：序列构造

- 对于每个 spell，构建三通道的状态序列 - 时间粒度：周（在清算前 30 天可加速到天） - 对不等长序列，使用 DTW 或 Optimal Matching 进行标准化

第二步：序列距离与聚类

- 使用多通道最优匹配（multi-channel optimal matching）计算 spell 两两之间的序列距离矩阵 - 替代成本矩阵（substitution cost matrix）基于状态的过渡概率或理论距离 - indel 成本（插入/删除成本）设为单位成本的 1/2 - 对距离矩阵做层次聚类（Ward's method） - 用轮廓系数/Calinski-Harabasz 伪 F 统计量确定最优聚类数

第三步：轨迹类型命名与信用检验

- 根据聚类中心的序列形态，命名轨迹类型（e.g., "慢性冒险型"、"预防型", "无为型"、"清算后重生型"） - 将轨迹类型作为自变量，进行信用预测赛马 - M0：传统风险指标（HF 路径特征、抵押率等） - M_BDM：M0 + 五个 BDM 维度（V4 流程，作为基线） - M_RAT：M0 + 轨迹类型（虚拟变量）+ 轨迹到清算距离 + 通道间同步度

第四步：决策锚——轨迹的可干预性

- BDM 告诉你"谁的分数高"，但 RAT 告诉你"下一个月他的轨迹如果不变，清算概率是 X%" - 轨迹的时间动态意味着可以通过干预转换概率来量化： - 如果处于"慢性冒险型"轨迹的用户被要求增加 10% 的抵押率，轨迹从"慢性冒险型"转为"谨慎型"的概率是多少？ - 这种转换如何改变期望清算损失？ - 这提供了比 BDM 更精确的治理干预靶点

4. 关键研究问题

- RQ1（轨迹形态学）：DeFi 借款人的风险调整行为可以归纳为哪几类典型轨迹？不同类型在序列形态上如何区分？ - RQ2（信用增量）：轨迹类型是否在传统风险指标和 BDM 维度之外，对清算风险有增量预测力？ - RQ3（方向性动态）：轨迹中的"转折点"（从一个行为模式转向另一个的时点）如何与外生市场事件（牛熊转换、协议参数变更、gas 价格飙升）相关？ - RQ4（治理干预设计）：基于轨迹的预测是否支持更精准的风险分层？转换概率是否能量化为治理策略的预期效果？

5. 失败判据与降级方案

失败场景判据降级方案
序列不可分型轮廓系数 < 0.2，聚类缺乏解释力放弃聚类，改用序列距离矩阵直接做预测（核方法）
RAT 无信用增量M_RAT vs M_BDM 的 AUC 差异不显著报告 RAT 与 BDM 等价——行为过程的线性压缩已经足够
主动行为样本不足面临与 V4 相同的 Safe 钱包/闪电贷窗口问题回到 V4 的 PoC 判断——如果主动行为不可靠分离，整个行为方向都受限
计算复杂度不可行对 200K+ spell 做最优匹配不可行使用 DTW 近似（有线性时间的 lower bound）或随机抽样代表性子集

7. 期刊与学术定位

- 主攻：经济学期刊强调方法严谨性的（Journal of Econometrics）或社会科学方法期刊（Sociological Methods & Research） - 次选：金融学期刊中欢迎方法创新的（Journal of Financial Econometrics）或计算社会科学（EPJ Data Science） - 定位差异：RAT 方法的创新点不是发明新算法，而是将社会学/生命历程研究中的序列分析工具首次系统性引入金融行为预测，并通过 DeFi 的全行为可观测性展示其优势

8. 核心风险

1. 方法论迁移的接受度：社会学方法在金融学/经济学中的接受度低。需要： - 在引言中正面论证"为什么截面偏差不能捕获信用相关的动态" - 提供模拟证据：展示两个 BDM 得分相同但清算风险完全不同的合成例子 2. 计算可扩展性：最优匹配的复杂度是 O(n²)，对计算资源有要求 3. 可解释性 vs 预测力：轨迹类型需要被赋予经济含义（不只是统计聚类） 4. 序列构造的选择偏误：以"开仓→还清"为一整个 spell 分析，会忽略那些永不还清的超长期交易者——需要敏感性检验 5. 与 V4 和 BDM 的关系：如果 BDM 人就在委员会上，RAT 的附加值必须清楚：BDM 告诉你偏差多大，RAT 告诉你偏差如何随时间演化以及这种演化模式是否是信用信号。

9. 是否值得做一个专用 PoC？

值得。最简单的 PoC：

1. 对 Aave V2 上 100 个 spell 做 single-channel 序列分析（仅"加抵押/还款/无行动"） 2. 人工标注是否可以视觉上区分"会清算"和"不会清算"的序列 3. 如果有 5+ 个人能区分，说明轨迹包含肉眼可见的信用信号，值得投入完整的序列分析方法

如果 PoC 失败（序列看起来完全随机），RAT 方向应被拒绝。

Branch B：DeFi 决策本体论——透明系统中的信用信息生产

核心直觉：DeFi 的"透明性"是一个陷阱。所有交易可见（交易透明）不等于有关偿付能力的信息可见（信用透明）。这个区分类似于：银行能看到你的银行卡账单（交易透明），但银行不知道你下个月会不会失业（不透明事件）。在 DeFi 中，借贷协议看到的是 on-chain actions，但它们看到的究竟是关于偿付能力的信号，还是仅仅是一个被公开记录的行为档案？如果是后者，那么"DeFi 是透明的"这句话在信用判断的意义上就是空洞的——它混同了"看得到"和"看得懂"。

1. 与 V4 的连续与断裂

连续性

- 继承 V4 的终极问题：纯链上行为能否用于信用判断？ - 继承观察者相对性（observer relativity）：什么信息对谁是可见的？ - 继承 V4 的所有数据基础设施（Dune 查询、HF 自计算、主动/被动区分）

断裂

- 理论锚点从行为经济学（Prospect Theory）彻底转向信息经济学（Information Economics）+ 本体论（Ontology） - V4 问："DeFi 借款人的行为偏差包含信用信号吗？" - Branch B 问："在 DeFi 中，'信用信号'本身是什么？它的生产条件是什么？透明性在什么条件下能产生真正的信用信息，在什么条件下只是制造 Noise？" - 这不是"扩展"V4，而是为 V4 的经验发现（如果 BDM 确实预测清算）提供一个更高层级的解释框架——"为什么"行为偏差包含信用信号

2. 理论框架（两层结构）

第一层：信息经济学——信用信息的本质

2.1 信息不对称的标准理论（Baseline）

Stiglitz & Weiss (1981) 的经典框架：信贷配给之所以存在，是因为银行无法区分"好"和"坏"的借款人（逆向选择），也无法完全监控借款人事后行为（道德风险）。结果是：利率上升 → 安全借款人退出 → 留在池中的平均风险上升 → 银行不提高利率而直接配给信贷。

这一框架的关键前提是：存在某种信息，它对于银行是不可观察的，但对于借款人是已知的。银行通过抵押、合约条款等机制来部分解决这个问题。

DeFi 的承诺是：因为它透明且无需信任，这些信息不对称问题已被消解。但这是否成立？

2.2 DeFi 中的信息生产悖论

在 DeFi 中： - ✅ 所有交易是公开可见的（全透明度） - ❌ 但偿付意愿和偿付能力不能从交易中直接读取

这就创造了一个有趣的翻转： - 在传统金融中，银行不透明（银行不知道你下个月是不是会失业）是一个缺陷 - 在 DeFi 中，协议完全透明（协议知道你的每个交易），但依然不知道你的偿付能力——全透明 = 全噪声

这是一个根本性的洞察：透明度是信息生产的条件，但也是信息过载的条件。在 100% 可观测的环境中，"信号"和"噪声"是同一样东西——取决于你用什么分析框架去组织它。

2.3 信息生产函数

因此，B 的理论贡献不是"DeFi 存在不对称信息"（这 trivial），而是提出信息生产函数（Information Production Function, IPF）的概念：

$$\mathcal{I}(x_t, \mathcal{F}_t) = \text{Signal}_{credit}(x_t | \mathcal{F}_t)$$

其中： - $x_t$ 是时间 $t$ 的链上行为（交易序列） - $\mathcal{F}_t$ 是信息治理框架（分析框架——本体、理论、模型） - $\mathcal{I}$ 是从原始行为中生产信用信息的过程 - 输出是"该行为对信用判断意味着什么"的信号

核心论题：$x_t$（行为）本身不包含信息——只有当一个本体论框架 $\mathcal{F}_t$ 被使用时，$x_t$ 才成为信用信号。如果你不知道你要找什么，你看不到任何东西。

> 这与"怎么都行"的哲学（Feyerabend）不同，更接近信息论中的"信号必须在接收端被解码"的编码理论。

第二层：决策本体论——为信用判断构造一个显式的知识结构

2.4 从"分析框架"到"本体"

如果信用信息的生产依赖于分析框架，那么什么框架更可能产生好的信号？

知识本体（Ontology）的工程传统（Gruber, 1995; Gómez-Pérez et al., 2004）提供了一套严格的概念化工具：

- 定义领域中的类（Class）：借款人类型、行为类型、风险类型 - 定义关系（Relation）：什么行为"证据"了什么能力/意愿 - 定义公理（Axiom）：逻辑规则——已知某行为，可以推断什么属性 - 定义实例（Instance）：具体地址的具体行为

关键创新：在 DeFi 中，交易的本体结构是自动可提取的。这是因为所有的交易都是形式化的（Ethereum 交易 = 一个标准化的数据结构）。在传统金融中，行为是高度非结构化的（柜台对话、邮件沟通、电话协商）——在 DeFi 中不是。

这意味着DeFi 是唯一一个可以为信用判断构建显式的、机器可读的本体的金融场景。这不是工程选择，是根本的结构属性。

2.5 Palantir 式推理的类比

Palantir 的核心洞察是：调查分析的瓶颈不是缺少数据，而是缺少语义整合——把不同来源、不同格式、不同粒度的数据映射到同一个概念框架中，让分析者可以问"这个人与这个人什么关系"而非"给我看这个表"。

在 DeFi 信用判断中，同样的问题存在： - 你能看到地址 A 在协议 X 上借了钱，地址 C 在协议 Y 上做了抵押 - 但这些事实必须被语义连接：地址 A 和地址 C 是同一个 label 吗？借的资产是不是来源于 Aave 的闪电贷？这个借款是用于杠杆还是真实消费？ - 这些连接需要的不是"更多数据"，而是一个显式的本体结构来决定哪些关系在信用判断中是相关的

Branch B 不是要构建 Palantir（工程上的)，而是要以本体的思维方式重新概念化 DeFi 中的信用信息生产问题。

3. 操作化方案

3.1 研究设计：两阶段的混合方法设计

阶段一：本体构建（定性/计算性）

1. 实体与关系的提取 - 从 Aave V2 的全部交互中，提取所有可观测的实体类型：EOA 地址、合约地址、Token 地址、协议地址 - 提取所有可观测的关系：转账、授权、借款、还款、清算、闪电贷 - 判断哪些关系在信用判断中是潜在相关的——不是所有关系都是信用信号

2. 本体定义（Conceptual Level） - 定义信用判断的基本概念：偿付意愿（willingness to repay）≠ 偿付能力（ability to repay） - 为每个概念定义可观测的"证据"：什么可观测行为用作"偿付能力"的证据？ - 示例： - 频繁的小额还款 → 证据：行为上的偿付意愿 - 在 HF=1.0 时加抵押 → 证据：对清算的认知，隐含的偿付意愿 - 从不显式地被清算（从不留下坏账） → 证据：历史偿付能力 - 持有 Cryptopunk / ENS → 证据：长期投资倾向，隐含低风险

3. 本体编码（Formal Level） - 将概念关系写成形式逻辑或一阶谓词

阶段二：本体验证——"信息性"的信度检验

1. 将"本体"转化为可计算的信用预测特征 2. 检验这些本体衍生特征在预测清算风险时的增量信度：与 BDM、HF 动态、账户属性等传统特征做赛马 3. 检验"本体的新信息"的独立性质

3.2 关键研究问题

- RQ1（本体存在性）：在 DeFi 信用判断中，哪些本体类型（偿付意愿、偿付能力）有显式的链上对应证据？哪些没有？ - RQ2（信息生产）：使用本体提取的特征是否超越了传统特征的信用预测力？ - RQ3（可泛化性）：定义在 Aave 上的本体是否可以转移到 Compound 而信息性不显著损失？

3.3 方法工具箱

- 形式概念分析（FCA）：Ganter & Wille (1999) 的 FCA 天然适合从对象-属性表中推导概念层次 - 描述逻辑（Description Logic）：用于写本体的形式语言 - 图神经网络（GNN） 作为近似实现：如果本体定义为图结构，GNN 自然可以学习图上的消息传递

7. 核心优势与风险

为什么 B 最原创

- DeFi 的"透明度"被反复讨论，但从信息生产的角度没有人做工作 - 把"本体"从工程工具升级为分析概念是一个跨学科动作（将 CS 本体与金融信息生产连接） - 可能是唯一一个不需要对大量数据进行复杂建模的方向（概念贡献就是主要贡献）

- 你需要说服三个不同的学科：信息系统（IS）学者、金融经济学审稿人、CS 本体工程师 - "本体"这个词在 CS 和社会科学中有完全不同的含义——需要大量 definitional work - 实证验证部分可能不足以支撑整个论文——如果本体特征与传统特征在预测力上等价，概念贡献是否成立？ - 委员会可能不理解为什么一个金融 PhD 要做"本体"

适用场景

- 适合高理论化的 PhD 论文或概念论文作为第一条主线 - 不适合作为硕士论文或投 CV/ML 导向的会议 - 如果被拒绝，B 可以退化为纯概念文章（风险更低，但影响力也更低）

Branch C：异质预期与演化响应函数——不假设普适行为常数的行为金融

核心直觉：V4 用前景理论为 DeFi 借款人假设了一个普遍的行为规则——所有人都有损失厌恶（$\lambda > 1$），都在参考点附近有参考点效应，都遵循递减敏感性。但 DeFi 的自选择性质意味着不同类型的借款人可能使用完全不同的行为策略："一些人是技术驱动的套利机器，盯着 HF 做到最优资本效率；一些人是信仰驱动的 HODLer，从不卖也不借；一些人是赌博驱动的杠杆狂，从 DeFi 借了钱去交易所开 100x 杠杆。"对这三类人，使用同一套前景理论参数是一种范畴错误——你把异质总体误认作同质个体。

1. 核心概念

1.1 异质代理人模型（Heterogeneous Agent Models, HAM）

起源：HAM 传统起源于 Brock & Hommes (1997, 1998) 对适应性信念系统的基础工作，后由 Hommes (2006) 系统化为一个完整的研究纲领。核心洞察：当代理人具有异质信念和自适应预期时，市场可以内生地产生复杂动态——从稳定均衡到混沌、从慢速收敛到剧烈波动——而这些动态在代表性代理人框架中是不可见的。 与 V4 的连接：HAM 不假定你"应该"使用什么偏好参数。它只是(1)定义一组可行的行为策略，(2)检验这组策略在种群中的分布，(3)研究这种分布如何随时间演化（通过选择压力或学习），(4)检验不同策略类型是否有差异化的经济结果。

1.2 演化响应函数（Evolutionary Response Functions）

概念层面："响应函数"是行为策略的数学形式——给定市场状态 $s$，类型 $k$ 的代理人的产出是决策函数 $d = f_k(s; \theta_k)$。"演化"指的是，策略的种群分布不是固定的——那些预测力更好的策略会增长份额，而那些结果更差的会被选择淘汰。 在 DeFi 上下文中的含义：

- 如果某种策略类型（如"HODLer"）在牛市中实现最多收益，在种群中的比例可能上升 - 如果另一种策略（如"主动杠杆管理"）导致爆仓/清算，在熊市中被清除 - 结果，行为偏差的分布本身就是内生的——它取决于市场和协议参数

2. 理论框架

2.1 从 V4 的前景理论到行为类型学

V4 的立场：

> 所有借款人都有损失厌恶 ($\lambda > 1$)，所以当他们接近 HF=1 时，他们会更努力地补救。

Branch C 的改造：

> 一些借款人可能确实是 $\lambda > 1$ 的损失厌恶者。但另一些人可能是 $\lambda < 1$ 的损失追求者（赌博者），或者是完全不一样的市场信念持有者（如 $HF > 1.5$ 就 OK）。对这三类人，观测到的同一个行为——加抵押——可能出于完全不同的原因，代表着完全不同的策略，并预示着不同的未来结果。

2.2 关键创新的形式化

定义 $N$ 个潜在行为策略（$k = 1, ..., K$），每个对应一个特定的响应函数：

$$a_{i,t} = f_k(HF_{i,t}, \text{MarketState}_t; \theta_k) + \epsilon_{i,t}^{(k)}$$

其中： - $a_{i,t}$ 是用户 $i$ 在时间 $t$ 采取的主动行为（加抵押、还款、增贷的 USD 金额） - $f_k$ 是策略 $k$ 的响应函数 - $HF_{i,t}$ 是用户 $i$ 当前的 health factor - $\text{MarketState}_t$ 是市场状态（牛市/熊市、波动率、gas 价格等） - $\theta_k$ 是策略 $k$ 的自由参数

与 V4 的关键区别：

- V4 隐式假设只有一个 $f$（所有人的前景理论反应），但用参数的异质性来解释拟合残差 - Branch C 显式地允许有 $K$ 个不同的 $f_k$ 在同时运作

这不仅仅是一个方法论的区别。如果 $K \geq 2$ 并且至少两类有明显的不同行为，这就意味着： 1. 总体的平均行为不是任何个人的行为——平均行为是一个统计虚构 2. 监管或治理干预必须考虑到谁将对干预做出响应（而不只是平均响应多少）

2.3 策略定义的原则

类型不能凭空编造。它们必须有： 1. 微观基础：什么优化问题导致了这个规则？（可以不是完全理性——启发式/动态学习/近理性预期都可以） 2. 可操作化：什么可观测行为会"标记"这个类型？ 3. 可证伪：什么行为可以反驳这个类型的存在？

候选策略类型（初步列举，需要数据验证）：
类型名称决策规则可观测标记清算风险含义
损失厌恶者 (Loss-Averse)HF 下降时补救 > HF 上升HF 下降时的加抵押幅度 vs HF 上升时的增贷幅度比 > 1低——主动管理

3. 操作化方案

3.1 两阶段实证策略

第一阶段：类型识别（无监督）

1. 为每个用户构建特征向量（全部是行为层面的，避免包含结果相关的特征）： - 主动行为的 HF 弹性（HF 下降 0.1，加抵押 USD 增加多少） - 主动行为的 HF 非对称性（HF 下降时的反应 vs HF 上升时的反应比——这是对每个个体的"微观 lambda"的测量） - 主动/被动比（主动行为次数 / 总交易次数） - 时间分布（是否有聚集的密集行为窗口） - 跨多仓行为（如果是多仓用户）

2. 对特征空间做聚类（Gaussian Mixture Model, GMM 或 k-means）

3. 为每个聚类分配策略标签——基于行为的可解释模式

4. 诊断检验： - 类内同质性：同一类内的用户是否跨时间、跨市场状态一致地相似？ - 类间异质性：不同类的行为模式在统计上是否可分？ - 时间稳定性：个体用户在不同时间段的类型分配是否一致（或按照 Markov 链风格转化）?

第二阶段：类型的信用信息

1. 将识别出的类型用作客户特征来预测清算——与 BDM 和 HF 动态进行赛马 2. 检验类型-类型转换（如"从 HODLer 变成损失追求者"）是否比纯 HF 和 BDM 维度有增量 3. 量化异质性：总体的行为方差多大程度来自类型内 vs 类型间

3.2 与现有 HAM 文献的连接

Brock & Hommes (1997, 1998) 的模型关注资产价格形成——不同类型的交易者（fundamentalist vs chartist）选择竞争策略，价格由哪种策略更成功所决定。Branch C 的实证目标更谦逊——它不要求资产定价，只要求： 1. 识别行为类型在 DeFi 中的存在 2. 检验不同类型是否有差异化的信用结果 3. 描述类型分布如何随市场状态而变化

如果成功，这将是 HAM 传统的一个自然实证拓展：从资产定价到信用行为。

4. 关键研究问题

- RQ1（类型存在性）：DeFi 借款人可以被分为几个可解释的行为策略类型？每一类占总体的比例是多少？ - RQ2（类型的稳定性与可转换性）：行为类型是稳定的人格特质，还是伺市场/协议状态而变的响应策略？类型转换本身是否包含信用信息？ - RQ3（信用预测的不同能力）：不同类型在清算风险上是否有显著差异？这些差异在控制传统特征和 BDM 后是否保持？ - RQ4（演化适应性）：类型的分布是否遵从"更成功者增长"的演化逻辑？是否存在市场/协议的"自然选择"作用？

Branch D：数据驱动最小重写——行为理论不可知的可发表单元

核心直觉：如果 V4 的前景理论在 PoC 中被拒绝——或者，更可能的是，如果实证结果不 conform 到任何一个统一行为理论——论文是否还能发表？Branch D 明确地说：能。

原因很简单：即使理论不知道，DeFi 借贷行为是否可以预测清算？这个问题本身就值得一篇论文。你可以砍掉所有关于"前景理论""损失厌恶""参考点效应"的理论包袱，只留四个纯粹的经验问题：

1. DeFi 借款人的主动行为是否系统性地随 HF 变化？（不管是不是前景理论） 2. 这些行为模式的统计规律是否比传统链上风险指标更好地预测清算？ 3. 跨协议行为的一致性是否说明行为不只是协议特殊性的 artifact？ 4. 如果我们将这些行为规律用于治理——提前清算、费率分层——福利变化是否是正的？

1. 与 V4 的关系

什么保留

- 全部经验基础设施：Aave/Compound 的 Dune 查询、HF 自计算管道、主动/被动分类树、BDM 的五维度构念、决策锚 $\Delta W$、赛马设计精神 - 全部 PoC 验证项：Safe 占比、闪电贷窗口、主动行为样本量、多协议变量可比性 - 全部数据治理方案：预注册、失败判据、交叉验证、跨链

- 无监督行为特征提取作为核心方法论支柱——去掉理论锚但保留方法严谨性 - 更强调"模式存在性"而不是"为什么存在"——模式是否存在是实证问题；原因可以讨论但不是必要条件 - 一个更诚实的研究边界——论文贡献是"发现"而不是"理论创新"——在摘要中说清楚

为什么这不是"理论无能"

正统的科学方法允许你发现"这里有一个规律"而不必知道"这个规律为什么存在"。大部分早期的实证经济学论文（从菲利普斯曲线到 GARCH 模型）都是先发现规律，后来才找到微观基础。Branch D 的对策正是回归这一传统——让数据说话，而不是让理论先验地约束你看到什么。

2. 核心理论框架（最小集）

2.1 仅三种经验假设

假设内容与 V4 的对应可证伪方法
E1：行为梯度借款人主动行为随 HF 单调变化（至少部分人）放松——不预设方向检验每个行为类型的方向：加抵押随 HF↓ 增加？（多数）还是随 HF↓ 减少？（少数——可能是损失追求者）
E2：行为惯性与信用控制了 HF 动态后，行为的历史惯性（过去的行为预测当前行为，超出理性解释）包含信用信息放松——不称"损失厌恶"用 behavior inertia = 当前行为 - 当前 HF 系数×当前 HF + 控制变量（在训练集外验证）
E3：增量信息行为特征的信用信息不是旧信息的线性编码这是 V4 的核心——保留传统赛马：行为特征位于纯 HF、活跃度、资产组合之上

注意关键的区别： - V4 说：行为偏差（相对于理性模型）预测清算 - Branch D 说：行为特征（未必要定义"理性模型"）预测清算

即使一个用户的行为是完全理性的（$\beta = \beta_{rational}$），如果你能可靠地估计 $\beta_{rational}$，并且 $\beta$ 值本身（"这个用户是高度响应 HF 的"）比 pure HF 或纯 HF 路径更好地预测清算，那就够了。你不需要前景理论来论证这一点。

2.2 BDM 的重新定位

在 V4 中，BDM（行为偏差指数）的五个维度直接服务于前景理论的三个核心预测。在 Branch D 中，相同的五个维度被重新解释为：

BDM 维度V4 解释Branch D 解释
补救超配度损失厌恶 → 反应大于理性预期用户的平均 HF 弹性（一个泛型的行为特征）
参考点跳变度参考点效应用户的 HF 穿越行为集中在一个窄范围 — 不论是不是 HF=1

3. 操作化方案（简化很多）

3.1 单篇论文的三层经验分析

第一层：行为模式识别

1. 为每个 spell（用户-开仓周期）提取全部链上行为特征： - HF 弹性（log 加抵押 ~ log HF） - HF 穿越行为的频率（每周穿越某个 HF 区间边界的次数） - 交易时段的集中度（Gini 系数） - 清算后可能恢复的所有特征（如清算后 30 天内的活动水平）

2. 对这些特征做因子分析或 PCA/稀疏 PCA——提取 3-5 个"行为因子"

3. 描述行为因子的统计分布——是一个峰还是多个峰？（如果多峰，Branch C 的异质假设被间接验证）

第二层：信用预测

1. 标准赛马： - M0：纯 HF + 抵押率（传统风险） - M1：HF 动态 + 波动率 + 趋势 - M2：M1 + 行为因子（BDM 等价物）——主判据 - M3：M2 + 跨协议行为一致性（根据 RQ3）

2. 报告： - 行为因子的系数解释（哪些行为模式降低风险？方向与 $E2$ 一致吗？） - 增量 AUC（与 M1 比较） - SHAP/特征重要性——哪个行为因子贡献最大？

第三层：治理模拟

1. 用 M2 的预测来对用户按清算概率分层（低/中/高风险） 2. 模拟治理策略的效果——将清算阈值从 1.0 提高到 1.05（对高风险用户）并评估： - 坏账减少 - 增加的费用收入 - 总福利变化 $\Delta W$

3.2 方法工具箱

- 主：逻辑回归（最透明、最可解释） - 辅（如果有强预测动机）：XGBoost 或 LightGBM（用于 SHAP 重要性分解） - 时间序列交叉验证：而不是随机交叉验证——避免前瞻偏误 - Catastrophic forgetting 检验：如果模型在熊市中训练的系数用于牛市的样本，性能变化多少？（外部效度检验）

# Branch C：异质预期与演化响应函数——不假设普适行为常数的行为金融

**核心直觉**：V4 用前景理论为 DeFi 借款人假设了一个普遍的行为规则——所有人都有损失厌恶（$\lambda > 1$），都在参考点附近有参考点效应，都遵循递减敏感性。但 DeFi 的自选择性质意味着**不同类型的借款人可能使用完全不同的行为策略**："一些人是技术驱动的套利机器，盯着 HF 做到最优资本效率；一些人是信仰驱动的 HODLer，从不卖也不借；一些人是赌博驱动的杠杆狂，从 DeFi 借了钱去交易所开 100x 杠杆。"对这三类人，使用同一套前景理论参数是一种**范畴错误**——你把异质总体误认作同质个体。

---

## 1. 核心概念

### 1.1 异质代理人模型（Heterogeneous Agent Models, HAM）

**起源**：HAM 传统起源于 Brock & Hommes (1997, 1998) 对适应性信念系统的基础工作，后由 Hommes (2006) 系统化为一个完整的研究纲领。核心洞察：当代理人具有异质信念和自适应预期时，市场可以内生地产生复杂动态——从稳定均衡到混沌、从慢速收敛到剧烈波动——而这些动态在代表性代理人框架中是不可见的。

**与 V4 的连接**：HAM 不假定你"应该"使用什么偏好参数。它只是(1)定义一组可行的行为策略，(2)检验这组策略在种群中的分布，(3)研究这种分布如何随时间演化（通过选择压力或学习），(4)检验不同策略类型是否有差异化的经济结果。

### 1.2 演化响应函数（Evolutionary Response Functions）

**概念层面**："响应函数"是行为策略的数学形式——给定市场状态 $s$，类型 $k$ 的代理人的产出是决策函数 $d = f_k(s; \theta_k)$。"演化"指的是，策略的种群分布不是固定的——那些预测力更好的策略会增长份额，而那些结果更差的会被选择淘汰。

**在 DeFi 上下文中的含义**：
- 如果某种策略类型（如"HODLer"）在牛市中实现最多收益，在种群中的比例可能上升
- 如果另一种策略（如"主动杠杆管理"）导致爆仓/清算，在熊市中被清除
- 结果，行为偏差的**分布**本身就是内生的——它取决于市场和协议参数

## 2. 理论框架

### 2.1 从 V4 的前景理论到行为类型学

V4 的立场：

> 所有借款人都有损失厌恶 ($\lambda > 1$)，所以当他们接近 HF=1 时，他们会更努力地补救。

Branch C 的改造：

> 一些借款人可能确实是 $\lambda > 1$ 的损失厌恶者。但另一些人可能是 $\lambda < 1$ 的损失追求者（赌博者），或者是完全不一样的市场信念持有者（如 $HF > 1.5$ 就 OK）。对这三类人，观测到的同一个行为——加抵押——可能出于完全不同的原因，代表着完全不同的策略，并预示着不同的未来结果。

### 2.2 关键创新的形式化

定义 $N$ 个潜在行为策略（$k = 1, ..., K$），每个对应一个特定的响应函数：

$$a_{i,t} = f_k(HF_{i,t}, \text{MarketState}_t; \theta_k) + \epsilon_{i,t}^{(k)}$$

其中：
- $a_{i,t}$ 是用户 $i$ 在时间 $t$ 采取的主动行为（加抵押、还款、增贷的 USD 金额）
- $f_k$ 是策略 $k$ 的响应函数
- $HF_{i,t}$ 是用户 $i$ 当前的 health factor
- $\text{MarketState}_t$ 是市场状态（牛市/熊市、波动率、gas 价格等）
- $\theta_k$ 是策略 $k$ 的自由参数

**与 V4 的关键区别**：
- V4 隐式假设只有一个 $f$（所有人的前景理论反应），但用参数的异质性来解释拟合残差
- Branch C 显式地允许有 $K$ 个不同的 $f_k$ 在同时运作

这不仅仅是一个方法论的区别。如果 $K \geq 2$ 并且至少两类有明显的不同行为，这就意味着：
1. **总体的平均行为不是任何个人的行为**——平均行为是一个统计虚构
2. 监管或治理干预必须考虑到**谁**将对干预做出响应（而不只是平均响应多少）

### 2.3 策略定义的原则

类型不能凭空编造。它们必须有：
1. **微观基础**：什么优化问题导致了这个规则？（可以不是完全理性——启发式/动态学习/近理性预期都可以）
2. **可操作化**：什么可观测行为会"标记"这个类型？
3. **可证伪**：什么行为可以反驳这个类型的存在？

**候选策略类型（初步列举，需要数据验证）**：

| 类型名称 | 决策规则 | 可观测标记 | 清算风险含义 |
|----------|----------|-----------|-------------|
| 损失厌恶者 (Loss-Averse) | HF 下降时补救 > HF 上升 | HF 下降时的加抵押幅度 vs HF 上升时的增贷幅度比 > 1 | 低——主动管理 |
| **损失追求者 (Loss-Chasing)** | 清算前加杠杆（赌博翻本） | HF<1.1 时**增加**杠杆而非补救 | 高——恶化位置 |
| 惯性持有者 (Inertia) | 几乎不交易 | 极低的交易频次 | 加密资产——随机，视市场而定 |
| 参考追踪者 (Reference-Tracker) | 当 HF 穿越"目标"线时行动 | HF 在 1.5 或 2.0 附近的行为断点 | 低-中 |
| 市场择时者 (Market-Timer) | 行为与市场状态高度相关（与仅 HF 相关相反） | 交易时机与市场涨跌高度同步 | 高——在上涨中加杠杆，下跌中不响应 |

这只是初步列表。实证上，类型必须从数据中用聚类或有限混合模型识别——不能被预设。

## 3. 操作化方案

### 3.1 两阶段实证策略

**第一阶段：类型识别（无监督）**

1. 为每个用户构建特征向量（全部是行为层面的，避免包含结果相关的特征）：
   - 主动行为的 HF 弹性（HF 下降 0.1，加抵押 USD 增加多少）
   - 主动行为的 HF 非对称性（HF 下降时的反应 vs HF 上升时的反应比——这是对每个个体的"微观 lambda"的测量）
   - 主动/被动比（主动行为次数 / 总交易次数）
   - 时间分布（是否有聚集的密集行为窗口）
   - 跨多仓行为（如果是多仓用户）

2. 对特征空间做聚类（Gaussian Mixture Model, GMM 或 k-means）

3. 为每个聚类分配策略标签——基于行为的可解释模式

4. 诊断检验：
   - **类内同质性**：同一类内的用户是否跨时间、跨市场状态一致地相似？
   - **类间异质性**：不同类的行为模式在统计上是否可分？
   - **时间稳定性**：个体用户在不同时间段的类型分配是否一致（或按照 Markov 链风格转化）?

**第二阶段：类型的信用信息**

1. 将识别出的类型用作客户特征来预测清算——与 BDM 和 HF 动态进行赛马
2. 检验类型-类型转换（如"从 HODLer 变成损失追求者"）是否比纯 HF 和 BDM 维度有增量
3. 量化异质性：总体的行为方差多大程度来自类型内 vs 类型间

### 3.2 与现有 HAM 文献的连接

Brock & Hommes (1997, 1998) 的模型关注**资产价格形成**——不同类型的交易者（fundamentalist vs chartist）选择竞争策略，价格由哪种策略更成功所决定。Branch C 的实证目标更谦逊——它不要求资产定价，只要求：
1. **识别**行为类型在 DeFi 中的存在
2. **检验**不同类型是否有差异化的信用结果
3. **描述**类型分布如何随市场状态而变化

如果成功，这将是 HAM 传统的一个自然实证拓展：从资产定价到信用行为。

## 4. 关键研究问题

- **RQ1（类型存在性）**：DeFi 借款人可以被分为几个可解释的行为策略类型？每一类占总体的比例是多少？
- **RQ2（类型的稳定性与可转换性）**：行为类型是稳定的人格特质，还是伺市场/协议状态而变的响应策略？类型转换本身是否包含信用信息？
- **RQ3（信用预测的不同能力）**：不同类型在清算风险上是否有显著差异？这些差异在控制传统特征和 BDM 后是否保持？
- **RQ4（演化适应性）**：类型的分布是否遵从"更成功者增长"的演化逻辑？是否存在市场/协议的"自然选择"作用？

---

## 5. 失败判据

| 场景 | 判据 | 方案 |
|------|------|------|
| 不存在可解释的类型 | 聚类质量差（无统计可区分聚类） | 回到 V4——假设同质行为模型可以被接受 |
| 存在类型但无信用预测力 | 不同类型的清算率无统计差异 | 有趣的非结果——报告行为方差≥信用方差 |
| 类型在时间上不稳定 | Markov 类型转换矩有短期记忆 | 接受类型是"状态依赖"的——这不是错，而是推动重新设计研究框架 |
| 演化逻辑缺失 | 没有证据显示成功类型的增长 | 报告"我们只有静态分布的证据，没有演化选择的证据" |

## 7. 期刊与学术定位

- **主攻**：
  - *Journal of Economic Dynamics and Control (JEDC)*：这是发表 HAM 研究的首要期刊。如果 Branch C 含有演化动态（类型分布的 Markov 转移、选择压力分析），JEDC 是自然归宿
  - *Quantitative Finance*：如果重点在于交易的微观计量与行为策略识别
- **次选**：
  - *Journal of Economic Behavior and Organization (JEBO)*：如果强调行为而不是计量
  - *Journal of Financial Stability*：如果框架的治理/政策含义被强调

**定位区别**：与 Branch A 不同，这一方向**不需要卖"新方法"——序列分析**。它卖的是新问题："大家都假定行为是同质的，但我们的数据显示不是——这意味着治理干预必须基于"谁"会受影响，而不是基于平均处理效应。"

## 8. 核心优势与风险

### 为什么 C 是最有对话感的方向
- HAM 文献是当前经济学中**少数几个还在快速增长的领域**（与 DSGE 的逆向趋势）
- 你的方向天然适合*JEDC* 或相关期刊——它只差一篇**实证应用**
- Branc 式推理可被 **"Litmus Test"思维**所支撑：现实远比假设复杂，但是否影响结论？

### 为什么 C 可能过于假设驱动
- 你需要假设有 K 个"策略"——但如果你选错了 K？
- 如果你的"策略类型"只是市场状态的 artifact？
- 解决方案：不要执着于 K——为每个用户估计一个"行为策略强度参数"（如"个人 micro-lambda"），然后检验这些参数的分布是否为单峰。如果是单峰，那说明同质假设是对的（前景理论成立）。如果不是，你就有一个支撑异质性的强证据。

### 特别的技术风险
- GMM/混合模型的收敛性在对数规模的数据上可能不稳定
- 需要决定"用户-时间窗口"的粒度——太粗（用户-月），分类噪声大；太细（用户-天），序列依赖不可忽略

## 9. 与 Branch A 和 Branch D 的关系

- **与 A (RAT)**：A 关心的是"轨迹形态"，C 关心的是"类型分布"。两者完全互补——一个用户在 A 中属于某个轨迹类型，在 C 中可能被归入某个行为策略类型。大部分情况下，这两者的一致性正是我们要找的东西。
- **与 D (数据驱动)**：D 是 C 的最简单版本——它直接检验"无监督聚类是否预测清算"，而 C 要求聚类由经济理论约束驱动的响应函数类型。

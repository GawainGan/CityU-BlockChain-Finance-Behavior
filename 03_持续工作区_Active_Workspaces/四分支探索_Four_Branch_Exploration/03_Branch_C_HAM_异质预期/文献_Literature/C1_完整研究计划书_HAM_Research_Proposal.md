# Branch C：异质预期与演化响应函数 — 完整研究计划书

**版本**：v1.0 | **日期**：2026-07-08 | **性质**：博士论文候选方向

---

## 摘要

V4 隐含地假设 DeFi 所有借款人共享同一行为规则——前景理论规定的损失厌恶（$\lambda > 1$）、参考点依赖和递减敏感性。Branch C 拒绝这一假设，提出 DeFi 借款人可能是**异质的**："损失厌恶者"（HF下降时补救 > HF上升时的行动）、"损失追求者"（HF下降时反而加杠杆——赌博翻本）、"惯性持有者"（从不交易）等等，他们共同存在于同一市场中。这一视角根植于异质代理人模型（Heterogeneous Agent Models, HAM）传统（Brock & Hommes 1997, 1998; Hommes 2006），但将其指向从"资产定价"调转为"信用行为"。本研究通过有限混合模型（Finite Mixture Model）从链上行为数据中无监督地识别这些策略类型，然后检验不同策略类型在清算风险上的差异，以及行为类型的分布是否随市场状态而"演化"——更成功的策略是否增长份额。这为理解 DeFi 治理干预（谁将响应？如何响应？）提供了比"平均处理效应"更细致的框架。

## 1. 动机与核心直觉

### 1.1 V4 的"平均行为人"问题

V4 将前景理论用作一个**通用**行为规则：所有借款人都被假定为损失厌恶的（prospect theory 的 $\lambda$ 参数 > 1），当 HF 下降时都会采取补救行动。该假设在方法论上表现为：对总体的行为反应进行回归，得到一个 **平均值** $\bar{\lambda} > 1$，然后声称这与前景理论一致。

但这里存在一个基本谬误——**总体的平均行为不等于任何个体的行为**。考虑以下两种人口构成的 DeFi 借贷市场，两者都在总平均上表现为 $\bar{\lambda} > 1$：

- **市场 X**：50% 是非常积极的 HODLer（$\lambda = 2$——他们会非常积极地加抵押），50% 是漠不关心者（$\lambda = 0$——不关心 HF 变化）。总平均 $\bar{\lambda} = 1.0$。
- **市场 Y**：100% 是温和的损失厌恶者（每个人的 $\lambda = 1.1$）。总平均 $\bar{\lambda} = 1.1$。

两个市场的平均行为几乎相同（1.0 vs 1.1），但根本的动态完全不同。在市场 X 中，清算发生在"漠不关心者"中，针对治理干预的响应只对"HODLer"有效。在市场 Y 中，每个人都会对干预做出相似而温和的反应。但 V4 的框架无法区分两者——两者都有一个"看起来像前景理论"的总平均行为。

### 1.2 HAM 的解答

异质代理人模型（Heterogeneous Agent Models, HAM）传统提供了解药。其核心洞察是：

1. **代理人根据明确的决策规则（"策略"）相互区分**——有些人可能是经验主义者（chartist），有些人是基本面主义者（fundamentalist），有些人是懒人（inertia holder）。每个人的行为由其策略决定。
2. **代理人不必要都使用相同的策略**——即使从同一数据上，不同的决策规则可以产生大相径庭的行为。市场可以在多个策略共存下运作。
3. **策略的分布可以因选择而演变**——那些预测更精准或利润更高的策略将增加其市场比重，而那些表现差的被淘汰。

Branch C 将这一套思想从资产定价移植到信用行为：
- **决策规则** = 借款人的**响应函数**——给定市场状态（如 HF）下采取什么行为
- **异质性** = 不同的响应函数类型，通过数据无监督地识别
- **演化** = 响应函数类型在清算/非清算结果上的分布随时间的重组

### 1.3 核心研究问题

1. **RQ1（类型存在性）**：DeFi 借款人的行为响应是否可以分为几个可解释的"策略类型"？每类占总体的比例是多少？
2. **RQ2（类型的稳定性和可转换性）**：行为类型是稳定的"人格特征"，还是随着市场/协议状态变化的"响应策略"？
3. **RQ3（信用预测力）**：不同类型的借款人在清算风险上是否有显著差异？差异在控制传统特征后是否持续存在？
4. **RQ4（演化适应性）**：这些类型的分布是否符合"更成功的类型增长"的演化逻辑？在什么样的市场条件下？

## 2. 理论框架

### 2.1 异质响应函数

定义 K 个潜在行为策略（$k = 1, ..., K$），每个对应一个特定的响应函数 $f_k$：

$$a_{i,t} = f_k(\text{HF}_{i,t}, \text{MarketState}_t; \theta_k) + \epsilon_{i,t}^{(k)}$$

其中：
- $a_{i,t}$ = 用户 $i$ 在时间 $t$ 的主动行为（加抵押的 USD 金额）
- $\text{HF}_{i,t}$ = 用户当前的健康因子
- $\text{MarketState}_t$ = 市场上下文（牛市/熊市、波动率、gas 价格）
- $f_k$ = 策略 $k$ 的响应函数（可能对相同的 HF 意味着不同的行动）
- $\theta_k$ = 策略 $k$ 的自由参数（例如，HF 弹性、反应的不对称性等）

**与 V4 的关键区别**：V4 假设只有一个 $f$（即前景理论规定的损失厌恶响应），Branch C 允许有 $K$ 个不同的 $f_k$ 同时存在。

### 2.2 策略的定义映射

候选策略（通过理论驱动，但实证选择）：

| 策略类型 | 响应函数 $f_k$ | 可观测的特征（如何从数据中"看到"它） |
|----------|---------------|-------------------------------------|
| 损失厌恶者（Loss-Averse） | HF 下降 1 个单位 → 加抵押 USD 增加 X；HF 上升 1 个单位 → 增贷 USD 增加 < X | 当 HF 下降时，行为弹性高；当 HF 上升时，行为弱 |
| 损失追求者（Loss-Chaser） | HF↓ → **增贷**（赌博翻本）或 提现抵押品 | 在 HF 接近 1.0 时借款更多的"鳄口"特征 |
| 惯性持有者（Inertia） | 对 HF 变化几乎没有反应 | 总交易频率极低，加抵押^1 欠款几乎为零 |
| 参考跟踪者（Reference-Tracker） | 只对 HF 穿越某个特定值（如 1.5）起反应 | HF 在 1.5 附近行为密集，而在 1.2 或 2.0 附近不密集 |
| 市场择时者（Market-Timer） | 行为与市场涨跌高度同步（而不是以 HF 为条件） | 在牛市中借款更多（理性还是非理性？），在熊市中不反应 |

### 2.3 有限混合模型识别

与 GMM (Gaussian Mixture Model) 不同，有限混合回归模型假设观测到的行为是由多个未观察到的**潜在类**（策略类型）混合产生的。

**模型规范**：

$$y_{i,t} = \begin{cases}
\beta_1 X_{i,t} + \epsilon_{i,t}^{(1)} & \text{with probability } \pi_1(\text{type}=1) \\
\beta_2 X_{i,t} + \epsilon_{i,t}^{(2)} & \text{with probability } \pi_2(\text{type}=2) \\
\vdots \\
\beta_K X_{i,t} + \epsilon_{i,t}^{(K)} & \text{with probability } \pi_K(\text{type}=K)
\end{cases}$$

其中：
- $y_{i,t}$ = 用户 $i$ 在时间 $t$ 的主动行为（加抵押/还债的金额）
- $X_{i,t}$ = 协变量（$\text{HF}_{i,t}$, $\Delta\text{HF}_{i,t-1 \to t}$, $\text{MarketState}_t$, 交互项）
- $\pi_k$ = 在人群中属于类型 $k$ 的概率
- $\beta_k$ = 类型特定的行为参数

通过 EM（Expectation-Maximization）算法估计，该算法在分配个体到最可能类型的步骤（E步）和重新估计类型特定的参数（M步）之间迭代。

## 3. 操作化方案

### 3.1 变量构造

**因变量**：主动行为（加抵押 + 还债金额 USD 的净和，正 = 防御型行动，负 = 风险型行动）

**主预测变量**：
- `Delta_HF`：过去 30 天的 HF 变化（负 = HF 下降）
- `Delta_HF_pos`：max(Delta_HF, 0)（HF 上升）— 仅正交互项
- `Delta_HF_neg`：min(Delta_HF, 0)（HF 下降）— 仅负交互项
- `HF_level`：当前 HF 水平（可能是非线性的——使用样条函数）
- `Market_Is_Bull`：ETH 的 30 天回报 > 0（二元变量）
- 各种交互项：用于区分不同策略类型如何对市场上下文做反应

**分组变量**（GMM 用来分类）：
- 用户的 HF 弹性的平均值和标准差
- 反应的不对称性（$|\beta_{\text{HF下降}}| - |\beta_{\text{HF上升}}|$）——这是对个体"lambda"的微观测量
- 主动/被动比（主动交易的次数 / 总交互数）
- 交易频次的 Gini 系数（是否在短期间歇性活跃 vs 连续活跃）

### 3.2 K 的选择

通过以下标准确定最优策略类型数：
1. **BIC (Bayesian Information Criterion)**：平衡似然值和参数数量——找最小 BIC
2. **ICL-BIC (Integrated Completed Likelihood)**：对数据聚类和模型-separation 的惩罚；在 K-means 等效下趋向于减少虚假类别
3. **最小类规模**：每个类的大小 ≥ 总样本的 10%（避免识别噪声驱动的细小类）
4. **实质可解释性**：每个类的平均行为轮廓是否有经济上的意义？

**典型结果**：通常在 K = 3 到 K = 6 之间找到最佳。

### 3.3 类型的信用验证

识别出类型后，进行以下检验：

1. **清算风险**：使用逻辑回归（预测：0/1 清算指标）检验类型的虚拟变量（K-1 个）联合显著
2. **增量风险**：在控制了传统特征（HF、抵押率）和 BDM 维度后，类型的选择性系数的显著性
3. **类型的异质效应**：受试者操作特征（ROC）曲线按类型分层——函数形状是否不同？

### 3.4 演化动态

识别出类型后，第二阶段分析"演化"：

1. 将用户按月分批，每月冬季计算类型分布
2. 计算切换矩阵 $P$（Markov 转移矩阵），其中 $P_{jk}$ = 从类型 $j$ 转到类型 $k$ 的概率
3. 检验：$P$ 是否偏离单位矩阵（即类型是固定的）？
4. 如果是随机的（$P \neq I$），类型的**演化适应性**：
   - 如果类型 A 的平均月利润 > 类型 B 的平均月利润，那么类型 A 的份额是否在随后的月份中增长？
   - 这可以通过 Granger 因果检验：`type_A_share_t` ~ `type_A_lagged_profit_t`

## 5. 与 Branch A 和 Branch D 的独特性

| 维度 | A (RAT 轨迹) | C (HAM 类型) |
|------|------------|------------|
| 分析单位 | 序列（时间轨迹） | 响应函数（类型） |
| 核心问题 | 借款人的完整行为历史的特点 | 借款人对即时状态的响应 |
| 方法论 | 序列分析 + 聚类 | 有限混合模型 |
| 如果假设错误 | "行为不需要是类型的——序列本身已有结构" | "序列不需要——只需状态依赖性" |
| 两者的互补？ | A 的轨迹类型也可以是 C 中的一种"分类机会" | C 的类型分配也可以用于 A 的序列生成 |

实际上，A 和 C 两者问相同的问题（"异质性是否存在？"），但用的是不同方法论放大镜：
- **A**：通过比较序列形态（序列作为整体）——对"长期行为模式"敏感
- **C**：通过比较即时响应函数——对"当地行为自适应"敏感

## 6. 失败判据与降级方案

| 失败场景 | 判据 | 降级方案 |
|----------|------|----------|
| 不存在可解释的类型 | BIC 随 K 单调递减——模型在增加K，但没有实质收敛 | 报告："没有证据支持多种行为类型——单一行为模型（前景理论）可能就足够了" |
| 存在类型但无信用预测力 | 不同类型的清算率无统计差异（F 检验 p > 0.10） | 报告："虽然行为差异很大，但它们不转化为信用差异"——重要的无结果 |
| 类型的非时间稳定性 | Markov 转换矩阵显示高度可变的类型分配 | 类型是"状态依赖"的——接受并重新框架为"响应函数的状态依赖性"（如"参考跟踪"只在HF接近参考点时激活） |
| 未发现演化适应 | 更成功的类型并未在随后的时期增长 | 报告："不支持演化压力——账户保留其行为类型，可能是基于不变的人格或环境因素" |

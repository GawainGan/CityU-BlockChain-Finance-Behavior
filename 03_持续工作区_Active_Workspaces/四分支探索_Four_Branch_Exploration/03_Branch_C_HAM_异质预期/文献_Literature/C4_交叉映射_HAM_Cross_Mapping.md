## 核心主张映射

### 主张 C1：DeFi 借款人可分为多个可解释的行为策略类型
**简述**：不是所有人都按照前景理论的"损失厌恶"($\lambda>1$)规则行动——存在多个不同的行为规则的混合。

| 项目 | 内容 |
|------|------|
| **文献支撑** | Brock & Hommes (1997) — 异质规则共存的理论可能性；Hommes (2006) — 风格化事实——启发式、异质性、选择；Cornelli et al. (2025) — 经验异质性证据 |
| **技术操作** | 在 user-month 面板数据上运行 GMM(FMM)，用 EM 算法估计 K 个类型的后验概率 |
| **可检验的零假设** | H0: K=1（即所有借款人共享同一行为规则） |
| **成功判据** | BIC 在 K≥3 达到最小；所有类的大小 > 10%；类的行为轮廓具有经济意义 |

### 主张 C2：行为类型是稳定的
**简述**：类型不是临时的，借款人倾向于坚持使用某个规则（即使规则本身是次优的）。

| 项目 | 内容 |
|------|------|
| **文献支撑** | Branch (2004) — 类型（预期中的）的持久性；Anufriev & Hommes (2012) — 个人在不同试验中保持他们的预测规则 |
| **技术操作** | 计算 Markov 转换矩阵的主对角线概率 (P_jj)；如果 P_jj > 0.5，可认为是"逐渐"稳定的 |
| **可检验的零假设** | H0: P_jj = 0.5（随机游走；类型是随机的） |
| **成功判据** | 测试对角线的单侧 t 检验显著大于 0.5 |

### 主张 C3：不同类型的清算风险不同
**简述**：属于不同行为类型的借款人有显著不同的清算概率。

| 项目 | 内容 |
|------|------|
| **文献支撑** | Gadzinski & Liuzzi (2025) — DeFi 的行为异质性与清算结果相关；Cornelli et al. (2024) — 不同类型的借贷结果 |
| **技术操作** | 用类型员资格虚拟变量预测违约的逻辑回归（RQ2） |
| **可检验的零假设** | H0: β_1 = β_2 = ... = β_{K-1} = 0（类型无关） |
| **成功判据** | F 检验 p < 0.01；某些类型的个体几率比显著 ≠ 1 |

### 主张 C4：行为类型分布演化
**简述**：更成功的规则（导致更高利润/更少清算的规则）在随后的时期中增长份额。

| 项目 | 内容 |
|------|------|
| **文献支撑** | Anufriev & Hommes (2012) — 选择压力导致更成功规则的份额增长 |
| **技术操作** | 回归: Δshare_{j,t+1} ~ profit_{j,t} |
| **可检验的零假设** | H0: β ≤ 0 |
| **成功判据** | β > 0 具有统计显著性（单侧 t 检验, p<0.05） |

## 风险控制映射

| 风险 | 缓解 |
|------|------|
| GMM 不收敛 | 使用更多随机初始值（例如 50 而不是 10-20）或切换到 k-means 聚类 |
| K 出现在策略上不可解释 | 报告"K 的选择受到聚类质量的驱动，但类型本身缺乏经济意义" |
| 类型不稳定（对角概率 < 0.7） | 过渡到 HMM — 将消费者类型视为隐藏状态并使用 Viterbi 算法估计路径 |
| 演化适应不存在 | 报告"没有自然选择——类型可能是由不变的心理特征驱动，而不是由表现反馈驱动" |

## 跨分支映射

| C 的主张 | 与 A(RAT) | 与 B(本体) | 与 D(数据驱动) |
|----------|----------|----------|-------------|
| 异质类型的存在 | A 使用轨迹而 C 使用函数等同——两者都是识别异质性的平行方法 | B 用本体的概念重新解释"类型"：什么样的债务偿付品德（偿付能力+意愿） | D 可能也会发现异质性——只不过以因子分数的形式 |
| 类型的稳定性与转换 | A 的轨迹类型通过构造稳定（序列是一次性聚类的），C 的转换矩阵证明系统的不稳定性 | B 认为类型的稳定性是一个"共识问题"——如果协议就什么是好借款人达成一致，类型自然稳定 | D 不关心稳定性——只看预测的净化力 |
| 类型的演化适应性 | A 没有提供演化解释——A 中的什么驱动了错误的轨迹？C 又补了一笔 | B 的进化等价物是——哪种借贷人的信息生产最有效 | D 会做出一个条件： "如果类型变得不能预测新的数据，那就将其丢弃" |

Branch C：异质预期与演化响应函数 — 完整研究计划书

版本：v1.0 | 日期：2026-07-08 | 性质：博士论文候选方向

摘要

V4 隐含地假设 DeFi 所有借款人共享同一行为规则——前景理论规定的损失厌恶（$\lambda > 1$）、参考点依赖和递减敏感性。Branch C 拒绝这一假设，提出 DeFi 借款人可能是异质的："损失厌恶者"（HF下降时补救 > HF上升时的行动）、"损失追求者"（HF下降时反而加杠杆——赌博翻本）、"惯性持有者"（从不交易）等等，他们共同存在于同一市场中。这一视角根植于异质代理人模型（Heterogeneous Agent Models, HAM）传统（Brock & Hommes 1997, 1998; Hommes 2006），但将其指向从"资产定价"调转为"信用行为"。本研究通过有限混合模型（Finite Mixture Model）从链上行为数据中无监督地识别这些策略类型，然后检验不同策略类型在清算风险上的差异，以及行为类型的分布是否随市场状态而"演化"——更成功的策略是否增长份额。这为理解 DeFi 治理干预（谁将响应？如何响应？）提供了比"平均处理效应"更细致的框架。

1. 动机与核心直觉

1.1 V4 的"平均行为人"问题

V4 将前景理论用作一个通用行为规则：所有借款人都被假定为损失厌恶的（prospect theory 的 $\lambda$ 参数 > 1），当 HF 下降时都会采取补救行动。该假设在方法论上表现为：对总体的行为反应进行回归，得到一个 平均值 $\bar{\lambda} > 1$，然后声称这与前景理论一致。

但这里存在一个基本谬误——总体的平均行为不等于任何个体的行为。考虑以下两种人口构成的 DeFi 借贷市场，两者都在总平均上表现为 $\bar{\lambda} > 1$：

- 市场 X：50% 是非常积极的 HODLer（$\lambda = 2$——他们会非常积极地加抵押），50% 是漠不关心者（$\lambda = 0$——不关心 HF 变化）。总平均 $\bar{\lambda} = 1.0$。 - 市场 Y：100% 是温和的损失厌恶者（每个人的 $\lambda = 1.1$）。总平均 $\bar{\lambda} = 1.1$。

两个市场的平均行为几乎相同（1.0 vs 1.1），但根本的动态完全不同。在市场 X 中，清算发生在"漠不关心者"中，针对治理干预的响应只对"HODLer"有效。在市场 Y 中，每个人都会对干预做出相似而温和的反应。但 V4 的框架无法区分两者——两者都有一个"看起来像前景理论"的总平均行为。

1.2 HAM 的解答

异质代理人模型（Heterogeneous Agent Models, HAM）传统提供了解药。其核心洞察是：

1. 代理人根据明确的决策规则（"策略"）相互区分——有些人可能是经验主义者（chartist），有些人是基本面主义者（fundamentalist），有些人是懒人（inertia holder）。每个人的行为由其策略决定。 2. 代理人不必要都使用相同的策略——即使从同一数据上，不同的决策规则可以产生大相径庭的行为。市场可以在多个策略共存下运作。 3. 策略的分布可以因选择而演变——那些预测更精准或利润更高的策略将增加其市场比重，而那些表现差的被淘汰。

Branch C 将这一套思想从资产定价移植到信用行为： - 决策规则 = 借款人的响应函数——给定市场状态（如 HF）下采取什么行为 - 异质性 = 不同的响应函数类型，通过数据无监督地识别 - 演化 = 响应函数类型在清算/非清算结果上的分布随时间的重组

1.3 核心研究问题

1. RQ1（类型存在性）：DeFi 借款人的行为响应是否可以分为几个可解释的"策略类型"？每类占总体的比例是多少？ 2. RQ2（类型的稳定性和可转换性）：行为类型是稳定的"人格特征"，还是随着市场/协议状态变化的"响应策略"？ 3. RQ3（信用预测力）：不同类型的借款人在清算风险上是否有显著差异？差异在控制传统特征后是否持续存在？ 4. RQ4（演化适应性）：这些类型的分布是否符合"更成功的类型增长"的演化逻辑？在什么样的市场条件下？

2. 理论框架

2.1 异质响应函数

定义 K 个潜在行为策略（$k = 1, ..., K$），每个对应一个特定的响应函数 $f_k$：

$$a_{i,t} = f_k(\text{HF}_{i,t}, \text{MarketState}_t; \theta_k) + \epsilon_{i,t}^{(k)}$$

其中： - $a_{i,t}$ = 用户 $i$ 在时间 $t$ 的主动行为（加抵押的 USD 金额） - $\text{HF}_{i,t}$ = 用户当前的健康因子 - $\text{MarketState}_t$ = 市场上下文（牛市/熊市、波动率、gas 价格） - $f_k$ = 策略 $k$ 的响应函数（可能对相同的 HF 意味着不同的行动） - $\theta_k$ = 策略 $k$ 的自由参数（例如，HF 弹性、反应的不对称性等）

与 V4 的关键区别：V4 假设只有一个 $f$（即前景理论规定的损失厌恶响应），Branch C 允许有 $K$ 个不同的 $f_k$ 同时存在。

2.2 策略的定义映射

候选策略（通过理论驱动，但实证选择）：

策略类型响应函数 $f_k$可观测的特征（如何从数据中"看到"它）
损失厌恶者（Loss-Averse）HF 下降 1 个单位 → 加抵押 USD 增加 X；HF 上升 1 个单位 → 增贷 USD 增加 < X当 HF 下降时，行为弹性高；当 HF 上升时，行为弱
损失追求者（Loss-Chaser）HF↓ → 增贷（赌博翻本）或 提现抵押品在 HF 接近 1.0 时借款更多的"鳄口"特征
惯性持有者（Inertia）对 HF 变化几乎没有反应总交易频率极低，加抵押^1 欠款几乎为零
参考跟踪者（Reference-Tracker）只对 HF 穿越某个特定值（如 1.5）起反应HF 在 1.5 附近行为密集，而在 1.2 或 2.0 附近不密集
市场择时者（Market-Timer）行为与市场涨跌高度同步（而不是以 HF 为条件）在牛市中借款更多（理性还是非理性？），在熊市中不反应

2.3 有限混合模型识别

与 GMM (Gaussian Mixture Model) 不同，有限混合回归模型假设观测到的行为是由多个未观察到的潜在类（策略类型）混合产生的。

模型规范：

$$y_{i,t} = \begin{cases} \beta_1 X_{i,t} + \epsilon_{i,t}^{(1)} & \text{with probability } \pi_1(\text{type}=1) \\ \beta_2 X_{i,t} + \epsilon_{i,t}^{(2)} & \text{with probability } \pi_2(\text{type}=2) \\ \vdots \\ \beta_K X_{i,t} + \epsilon_{i,t}^{(K)} & \text{with probability } \pi_K(\text{type}=K) \end{cases}$$

其中： - $y_{i,t}$ = 用户 $i$ 在时间 $t$ 的主动行为（加抵押/还债的金额） - $X_{i,t}$ = 协变量（$\text{HF}_{i,t}$, $\Delta\text{HF}_{i,t-1 \to t}$, $\text{MarketState}_t$, 交互项） - $\pi_k$ = 在人群中属于类型 $k$ 的概率 - $\beta_k$ = 类型特定的行为参数

通过 EM（Expectation-Maximization）算法估计，该算法在分配个体到最可能类型的步骤（E步）和重新估计类型特定的参数（M步）之间迭代。

3. 操作化方案

3.1 变量构造

因变量：主动行为（加抵押 + 还债金额 USD 的净和，正 = 防御型行动，负 = 风险型行动） 主预测变量：

- Delta_HF：过去 30 天的 HF 变化（负 = HF 下降） - Delta_HF_pos：max(Delta_HF, 0)（HF 上升）— 仅正交互项 - Delta_HF_neg：min(Delta_HF, 0)（HF 下降）— 仅负交互项 - HF_level：当前 HF 水平（可能是非线性的——使用样条函数） - Market_Is_Bull：ETH 的 30 天回报 > 0（二元变量） - 各种交互项：用于区分不同策略类型如何对市场上下文做反应

分组变量（GMM 用来分类）：

- 用户的 HF 弹性的平均值和标准差 - 反应的不对称性（$|\beta_{\text{HF下降}}| - |\beta_{\text{HF上升}}|$）——这是对个体"lambda"的微观测量 - 主动/被动比（主动交易的次数 / 总交互数） - 交易频次的 Gini 系数（是否在短期间歇性活跃 vs 连续活跃）

3.2 K 的选择

通过以下标准确定最优策略类型数： 1. BIC (Bayesian Information Criterion)：平衡似然值和参数数量——找最小 BIC 2. ICL-BIC (Integrated Completed Likelihood)：对数据聚类和模型-separation 的惩罚；在 K-means 等效下趋向于减少虚假类别 3. 最小类规模：每个类的大小 ≥ 总样本的 10%（避免识别噪声驱动的细小类） 4. 实质可解释性：每个类的平均行为轮廓是否有经济上的意义？

典型结果：通常在 K = 3 到 K = 6 之间找到最佳。

3.3 类型的信用验证

识别出类型后，进行以下检验：

1. 清算风险：使用逻辑回归（预测：0/1 清算指标）检验类型的虚拟变量（K-1 个）联合显著 2. 增量风险：在控制了传统特征（HF、抵押率）和 BDM 维度后，类型的选择性系数的显著性 3. 类型的异质效应：受试者操作特征（ROC）曲线按类型分层——函数形状是否不同？

3.4 演化动态

识别出类型后，第二阶段分析"演化"：

1. 将用户按月分批，每月冬季计算类型分布 2. 计算切换矩阵 $P$（Markov 转移矩阵），其中 $P_{jk}$ = 从类型 $j$ 转到类型 $k$ 的概率 3. 检验：$P$ 是否偏离单位矩阵（即类型是固定的）？ 4. 如果是随机的（$P \neq I$），类型的演化适应性： - 如果类型 A 的平均月利润 > 类型 B 的平均月利润，那么类型 A 的份额是否在随后的月份中增长？ - 这可以通过 Granger 因果检验：type_A_share_t ~ type_A_lagged_profit_t

Branch C 文献支撑与理论溯源：异质代理人模型 × 行为金融 × DeFi

文献支撑体系概览

Branch C 的文献根植于两个学术传统：(1) 异质代理人模型 (HAM)——提供"为什么异质性重要"以及"如何建模"的理论基础；(2) DeFi 中的借贷行为——提供待研究的数据环境和现有知识。

第一部分：HAM 文献——提供"为什么平均行为是骗人的"

1.1 HAM 的经典起源

Brock, W.A. & Hommes, C.H. (1997). A Rational Route to Randomness. Econometrica, 65(5), 1059-1095.

- 核心论点：提出了异质信念的"适应性信念系统"（Adaptive Belief Systems, ABS）框架——不同类型交易者对市场价格的未来有不同的预测规则，切换规则基于规则的过去预测精度。ABS 内生地产生了从稳定到混沌的资产价格动态。这是 Branch C 的理论底座。 - 对 Branch C 的支持：直接的类比。ABS 中的"预测规则"在 Branch C 中变为"行为策略"。虽然 B&H (1997) 是关于价格形成，但同样的结构——多个异质规则共存、规则竞争（基于表现）、分布取决于相对表现——可以映射到信用行为。如果 K 个行为策略共存于 DeFi 借贷市场中，每种策略有不同清算风险，那么清算风险的分布是由这些策略的竞争决定的——不仅仅是外部的 HF 水平。

Brock, W.A. & Hommes, C.H. (1998). Heterogeneous Beliefs and Routes to Chaos in a Simple Asset Pricing Model. Journal of Economic Dynamics and Control, 22(8-9), 1235-1274.

- 核心论点：进一步探索参数如何影响从稳定走向混沌的路径——通过改变策略选择强度（选择随着相对表现越来越好）的强度，系统可以在稳定（一种信念主导）和复杂动态（多种信念共存，导致波动）之间转换。 - 对 Branch C 的支撑：为 Branch C 的 RQ4（什么驱动类型分布的转变？）提供了技术框架。如果"选择强度"在 DeFi 中对应于"多强的利润/损失反馈改变借款人的行为规则"，那么牛市中高的选择强度（快速切换到成功策略）可能导致一种类型（如市场择时者）的爆发性增长——而熊市中的选择可能不同。

1.2 HAM 的实证传统

Hommes, C.H. (2006). Heterogeneous Agent Models in Economics and Finance. In Handbook of Computational Economics, Vol. 2, 1109-1186.

- 核心论点：系统综述了 HAM 的整个研究纲领——从理论动机、代理人的微观行为证据、到学习、选择和自组织的宏观影响。尤其重要的是，Hommes 指出了实证文献中 HAM 的关键"风格化事实"： 1. 代理人使用简单的启发式规则（不完全是理性的） 2. 代理人是异质的（不同的启发式） 3. 代理人通过选择机制切换规则（演化） - 对 Branch C 的支撑：将 B&H 的理论路线图映射到 DeFi 的具体上下文——这是一个全新的实证环境（从实验室到现场）。Hommes 学术脉络为 Branch C 提供了 HAM 的"风格化事实"——如果这些事实也适用于 DeFi 中的借款人，Branch C 的假设可被广泛接受。

Anufriev, M. & Hommes, C.H. (2012). Evolutionary Selection of Individual Expectations and Aggregate Outcomes. American Economic Journal: Microeconomics, 4(4), 35-64.

- 核心论点：从实验设置中估计微观层面的预期形成机制。使用数据来区分各种预测规则（朴素预期、适应性预期、趋势外推等），然后观察哪种规则在实验中被参与者更频繁地使用以及这种演化如何影响市场价格。 - 对 Branch C 的支撑：直接的方法类比——"实验"被替换为"DeFi 现场环境"；"预测规则"被替换为"行为策略"。A&H (2012) 展示了如何通过模拟数据来估计规则类型并统计哪种规则在宏观层面上(市场层面)被更频繁地使用。这为 Branch C 的"演化适应" (RQ4) 提供了实证框架。

Branch, W.A. (2004). The Theory of Rationally Heterogeneous Expectations: Evidence from the Survey of Professional Forecasters. The Economic Journal, 114(497), 861-884.

- 核心论点：使用专业预测者的调查数据，发现代理人之间存在显著的认知异质性——不同的预测者使用不同的预测模型，并且这些异质性对总结果有聚合影响。该文被广泛认为是 HAM 传统的经验支柱。 - 对 Branch C 的支撑：Branch (2004) 使用调查数据来辨识预测类型的策略——Branch C 使用交易数据来辨识行为类型的策略。两者的平行法包括： - 输入数据：调查 vs 链上 - 策略：市场预测规则 vs 行为规则 - 选择机制：规则选择强度（取决于过去表现）vs 清算压力（取决于过去结果）

1.3 异质代理人在经济/金融中的更新应用

Dosi, G., Napoletano, M., Roventini, A. & Treibich, T. (2020). Rational Heuristics? Expectations and Behaviors in Evolving Economies with Heterogeneous Interacting Agents. Economic Inquiry, 58(2), 768-791.

- 核心论点：提出了一个框架，其中代理人使用简单的启发式规则（不是充分理性的），但规则可以通过演化学习（如分类器系统）而被改进——这不是一次性完全理性的，而是通过适应性试错学习。引用 Dosi 为 Branch C 提供了 HAM 传统的"启发式版本"。 - 对 Branch C 的支撑：分支 C 的行为策略可以与该文的"简单启发式"联系起来——借款人可能不是充分优化的理性人，但他们的行为可能是"近理性"的（使用简单的 if-then 规则）。这与"演化学习"（如果一种规则导致损失，就被替代）的框架兼容。

第二部分：行为类型学文献 - 提供DeFi行为策略的类型来源

2.1 异质行为类型的理论基础

Fagiolo, G. & Roventini, A. (2017). Macroeconomic Policy in DSGE and Agent-Based Models Redux: New Developments and Challenges. Journal of Artificial Societies and Social Simulation (JASSS), 20(1).

- 核心论点：比较了两种宏观建模方法——DSGE（代表性代理人，理性预期，同质）vs ABM（异质代理人，有限理性，基于规则）——的预测精度和政策效用。发现 ABM 在危机预测、异质效应的展示和政策传输机制方面显著优于 DSGE。 - 对 Branch C 的支撑：该文的方法论比较为 Branch C 提供了"为什么要拒绝同质行为假设"的宏观论证。如果同质假设在宏观政策分析中不成立（因为遗漏了异质性），那么在 DeFi 的微观政策设计中也不应该被接受（因为清算风险可能高度集中在某些行为类型的借款人之中）。

Sato, Y. & Hommes, C.H. (2014). An Experimental Study of Short-Run and Medium-Run Dynamics in Explaining Asset-Pricing Anomalies. Journal of the European Economic Association, 12(2), 362-401.

- 核心论点：在实验资产市场中，发现有两类交易者——“快速切换者”（根据近期回报调整预期）和“慢速切换者”（在更长的时间框架上操作）。这些类型化有助于解释资产价格中的短期和中期动态。 - 对 Branch C 的支撑：为 Branch C 提供了直接的类比——在 DeFi 借贷中，"慢速切换者"可能是那些只对长期趋势作出响应的借款人，"快速切换者"可能是那些对短期 HF 变化作出高弹性反应的借款人。两者共存意味着需要两种干预政策。

2.2 金融中的类型识别方法

Huang, X., Jin, Q., & Wang, Y. (2016). A Mixture Model Approach to the Anomaly Portfolio Construction. Review of Financial Studies (working).

- 核心论点：提出了基于有限混合模型的"异常检测方法"——将股票投资组合按其对异常因子的敏感性分为多个潜在子类，这些子类的收益来源是异质的（某些由动量驱动，另一些由价值驱动）。这比选择所有对相同因子敏感的股票的简单方法要好得多（因为那些同类的股票实际上对因子有不同的负载）。 - 对 Branch C 的支撑：直接的方法类比——"因子"在 Branch C 中是行为对 HF 的弹性；"异常组"是行为类型。正如 Huang et al. (2016) 发现不同股票对因子的暴露程度不同，Branch C 考察了不同用户对 HF 变化的暴露程度（高弹性类型 vs 低弹性类型）。

第三部分：DeFi 文献——提供现场环境和行为证据

3.1 DeFi 行为中的异质性证据

Gadzinski, G. & Liuzzi, D. (2025). Three Essays on DeFi Lending Markets.

- 核心论点：(基于早期探索文件) —— 发现清算后的行为恢复存在显著异质性：有的被清算者会重新开仓（"清算后重生"），有的则不会。这本身就提示可能有两种行为类型——被清算后恢复的和那些被清算后就离开的。 - 对 Branch C 的支撑：这段异质性证据是 Branch C 的类型学（RQ1）的经验基础——"为什么有些被清算者会回来而有些不会？这本身就证明有不同类型！"

Cornelli, G. et al. (2025). DeFi Lending and Collateral Choices.

- 核心论点：(同上) —— 也发现抵押品选择有异质性：有的借款人只使用稳定币（保守），有的在稳定币和波动币之间切换（善于时机选择），有的只使用波动币（冒险/持有）。这种行为类型可能对应于不同的内在抵押品偏好。 - 对 Branch C 的支撑：为"策略类型"提供了直接的经验支撑——如果有些用户 "保守"，有些"激进"，有些"择时"，那么我们就有了 K≥3 个策略类型。

Branch C 技术方案：有限混合模型与演化动力学

版本：v1.0 | 日期：2026-07-08

1. 数据准备

1.1 单位与度量

- 分析单位：用户-月（同 V4，保持可比性） - 因变量（行为）：危机应对行为 USD（加抵押 + 还款的净USD） - 预测变量： - 核心：HF 变化（ΔHF，测量为过去 30 天的差异，如果本月的平均 HF 与上月不同） - 调节：市场状态（牛市/熊市指标）、波动率（ETH 30 天波动率） - 交互项：ΔHF × MarketBull, ΔHF × HF_pre（状态依赖性） - 分组变量（用于潜在类别识别）： - 平均 HF 弹性（β_HF）：当月 log 主动行为对 ΔHF 的时间序列回归 - 反应的非对称性：|β_HF下降| - |β_HF上升| - 主动/被动比率 - 时间模式的 Gini 系数

1.2 样本构造

- 训练集：按 spell 的第一年（每个 spell 的前 12 个月）识别行为类型——这确保"类型分配"不会受未来的清算结果污染 - 检验集（清算预测）：spell 的剩余月（或使用后续的月）——检验类型的预测力 - 稳健性：使用滚动窗口（如 6 个月）而不是固定窗口进行类型分配

2. 有限混合模型（FMM）——第一阶段：类型识别

2.1 模型规范

使用带有时变截距的有限混合线性模型（因为行为基线水平在类型间可能不同）：

$$y_{it} = \alpha_k + \beta_k \cdot \text{HF_change}_{it} + \gamma_k \cdot X_{it} + \epsilon_{it}^{(k)}$$

其中： - $y_{it}$ = 用户 $i$ 月份 $t$ 的主动行为（USD） - $\text{HF_change}_{it}$ = 用户 $i$ 在时间 $t$ 与 $t-1$ 月间的 HF 变化 - $X_{it}$ = 额外的调节变量（市场状态等） - $\alpha_k$ = 类型特定的基线行为水平（惰性 vs 活跃） - $\beta_k$ = 类型特定的对 HF 的响应（弹性） - $\gamma_k$ = 类型特定的调节效应

误差项的分布：可使用 $\epsilon_{it}^{(k)} \sim \mathcal{N}(0, \sigma_k^2)$（同方差同类型）或 $\epsilon_{it}^{(k)} \sim \text{Student-t}(df)$（厚尾，对离群值的稳健性更好）

2.2 EM 算法的两个步骤

E步骤：计算每个（用户-月）属于每个类型k的后验概率

$$p(\text{type}_i = k | y_i, X_i) = \frac{\pi_k \cdot \mathcal{L}(y_i | \beta_k, \sigma_k^2)}{\sum_{j=1}^K \pi_j \cdot \mathcal{L}(y_i | \beta_j, \sigma_j^2)}$$

其中 $\mathcal{L}$ 是正态似然，$\pi_k$ 是混合权重。

M步骤：使用后验概率作为权重，重新估计每个子模型的参数

$$\hat{\beta}_k = \left( \sum_i w_{ik} X_i' X_i \right)^{-1} \left( \sum_i w_{ik} X_i' y_i \right)$$

其中 $w_{ik} = p(\text{type}_i = k | y_i, X_i)$，更新 $\pi_k = \frac{1}{N} \sum_i w_{ik}$

2.3 实施考量

- 起始值：多次随机启动（10-20次），提取最佳似然值——避免局部最优 - 收敛：当对数似然的变化 < 0.001 时停止 - 多重共线性：先进行 VIF 检验

3. 模型选择：K 的最终确定

3.1 统计标准

标准公式目标优点缺点
BIC-2LL + K×log(N)最小化易于计算，惩罚添加参数趋向于欠拟合（选择简单模型）
ICL-BICBIC + 2*entropy_of_partition最小化避免选择聚类结构弱的模型偶尔会选择更少的类
AIC-2LL + 2K最小化逼近真实模型的预测能力比 BIC 更容易过拟合

3.2 聚类质量与稳定性

- 轮廓宽度（每个后验概率的最高值的平均）——范围为 0-1，接近 1 = 完美的类分离 - Bootstrapped Jaccard 相似性（在两个独立样本上计算结果聚类的一致性）——如果聚类不稳定，这个值随变化

3.3 实质可解释性

最终 K 的每一类必须有一个可解释的、经济上有意义的轮廓： - 平均 HF 弹性：正（弹性型）vs 负（逆响应型） - 弹性的非对称性：负的非对称性 = 损失厌恶；正的非对称性 = "追求"

最终，通常会选择 3-5 类。

4. 预测建模——第二阶段：类型与清算

4.1 模型的比较

使用逻辑回归（因变量 = 0/1 在随后的 T 个月内被清算）赛马：

模型特征
M0HF指标（min, mean, sd）+ 抵押率
M1M0 + BDM 五维
M_traitM0 + 类型成员（K 个虚拟变量，K-1 个进入）
M_trait_allM0 + BDM + 类型成员

4.2 关键检验

1. 类型的增量信息：对 M_trait 中 K-1 个类型虚拟的 Wald 检验（H0：所有系数=0） 2. 类型是否压倒了 BDM 的信息：比较 M_trait 的 AUC 对比 M1 的 AUC？谁更高这就是谁的优胜性？ 3. 类型的风险量化：每个类型的边际效应（从 M_trait 返回的几率比）——"属于损失追求者类型的清算几率是基准类型的 X 倍"。

4.3 时间稳定性——类型转换

转换矩阵：定义一个 (K × K) 矩阵 $P$，其中 $P_{jk}$ = 用户今天在类型 j 而下期转向类型 k 的概率。从以下经验中估计：

- 对于每个用户-月，取其类型（由上述 FMM 的后验概率给出）→ 该用户在第 t+1 个月的类型 - 计算 $P_{jk} = \frac{\#\{i: \text{type}_i(t)=j, \text{type}_i(t+1)=k\}}{\#\{i: \text{type}_i(t)=j\}}$

对角主导检验：如果 $P_{jj} < 0.7$ 对某个 j，那么类型 j 的成员在期与期之间是不稳定的——类型是临时的并且不是固定的"类型"。 后果：如果对角主导不成立（$P_{jj} \ll 0.7$），那么需要使用隐马尔可夫模型（HMM），其中类型不能直接观测，而是一个隐藏的状态。

4.4 演化适应——类型分布是否有选择压力

针对每个类型 j 和使用月份 t，计算： 1. 类型 j 的月均利润（mean_profitt_j = 当月类型 j 中所有用户的加权收益的平均值） 2. 下个月（t+1）的类型 j 的比例（share_{j, t+1}）

然后回归： $$\Delta share_{j,t+1} = \alpha + \beta \cdot profit_{j,t} + \epsilon_{j,t+1}$$

如果 β > 0 且统计显著，有证据表明：利润高的类型更可能在接下来的时期扩大份额——演化适应存在。

替代：Granger 因果检验。

5. 稳定性与灵敏度

敏感性主要规范替代规范为什么重要
混合分布正态（Gaussian）Student-t (df=4) 或偏态正态HF 弹性的分布可能是厚尾的（一些用户对 HF 有大反应，大多数无反应）
K 的选择BIC-minAIC, ICL-BIC确保聚类数不受单一标准驱动
类型名称Iyengar et al. 标签交替标记确保类型命名不武断
时间范围月度双周/季度太短的窗口噪音大，太长会失去动态
市场状态拆分牛市/熊市合并类型分布可能取决于市场状态（不是固有的"类型"）

6. 工具与实现

- FMM 估计：R 中的 flexmix 或 mclust 用于参数估计 - HMM 版本：如果需要，使用 depmixS4 - 逻辑回归：R 的 glm 或 lme4 如果包含随机效应 - ROC 对比：pROC::roc.test 进行 DeLong 检验 - 非参数图：R 的 ggplot2 用于澄清 K 类间的轮廓差异

EM 估计应使用多次随机启动（至少 10-20 次），提取最佳对数似然以避免局部最优解。所有 p 值应用 Bonferroni 校正多重比较。

# Branch A 理论-技术-主张交叉映射表

## 说明

本映射表追踪每一条 RAT 的核心主张 $\to$ 支撑该主张的理论/文献 $\to$ 操作化该主张的技术步骤。目的是确保论文的每个声明在理论/文献上有退路，在技术上有可执行路线。

## 核心主张映射

### 主张 A1：行为序列形态包含超越截面偏差的信息
**简述**：两个 BDM 得分相同的借款人，其时间序列形态可能完全不同，而这种形态差异包含额外的信用信号。

| 项目 | 内容 |
|------|------|
| **理论/文献支撑** | Abbott (1995) — 序列形态优于截面属性的方法论论证；Aisenbrey & Fasang (2010) — 多通道序列捕获的信息量远超单维度 |
| **技术操作** | 对于每个 spell，构建三通道状态序列；计算多通道序列距离；聚类；比较"同BDM不同类"的两组人的清算率 |
| **可检验的零假设** | H0: 在属于不同轨迹类型但 BDM 五维得分无统计学差异的 spell 子集中，两类的清算率相等 |
| **成功判据** | 上述子集中的类间清算率差异在 5% 水平上显著（通过费希尔精确检验） |
| **如果该主张失败** | 说明"截面BDM已经足够概括借款人的行为信息——序列形态没有提供额外信息" |

### 主张 A2：DeFi 借款人可以分为多个稳定可解释的轨迹类型
**简述**：通过序列分析+聚类，行为序列自然地分为 5-7 个典型的轨迹类型，每类有独特的形态。

| 项目 | 内容 |
|------|------|
| **理论/文献支撑** | Nagin (2005) 的GBTM — 轨迹类型在多个领域中都稳定存在；Piquero (2008) — 跨情境的轨迹稳健性 |
| **技术操作** | 随机抽样 15K spell → 构建三通道序列 → 多通道DTW/OM距离 → Ward's 层次聚类 → 最佳聚类数选择（CH统计量 ） |
| **可检验的零假设** | H0: 轮廓系数 < 0.2（不存在聚类结构） |
| **成功判据** | ASW > 0.5；至少 3 个聚类（最多 7 个）每个占总体的 > 5%；聚类中心具有经济上可命名的典型形态 |
| **如果该主张失败** | 改用 DTW 核距离 + 核逻辑回归直接做预测（不需要聚类）；或报告"行为序列没有结构性聚类" |

### 主张 A3：多通道分析优于单通道分析
**简述**：同时分析行动、HF 区间和抵押品态度，比仅分析行动通道（只问"做了什么"不问"在什么风险状态下做的"和"伴随的风险态度是什么"）有更强的信用预测力。

| 项目 | 内容 |
|------|------|
| **理论/文献支撑** | Gauthier et al. (2010) — 多通道序列的操作指导；Cornelli et al. (2025) — 抵押品切换行为的信息；Gadzinski & Liuzzi (2025) — 清算后恢复与 HF 动态的交互 |
| **技术操作** | 比较以下三个聚类的信用预测力: (a) 仅行动通道聚类的轨迹类型，(b) 仅HF通道聚类的轨迹类型，(c) 三通道聚类的轨迹类型 |
| **可检验的零假设** | H0: (c) 的信用预测AUC = max((a)的AUC, (b)的AUC) |
| **成功判据** | (c) 的 AUC 显著高于 (a) 和 (b) |
| **如果该主张失败** | 说明单通道（尤其是HF通道）已经足够 — 行动和抵押品态度不提供额外信息 |

### 主张 A4：轨迹类型的信用预测力超越BDM指数
**简述**：控制了 BDM 五维度和 HF 动态后，轨迹类型虚拟变量的系数仍然显著。

| 项目 | 内容 |
|------|------|
| **理论/文献支撑** | Demyanyk & Van Hemert (2011), Deng & Quigley (2004) — 动态过程比静态快照在金融中信息更多；Stiglitz & Weiss (1981) — 信用信息需要"时间深度" |
| **技术操作** | 赛马模型 M3（M0 + BDM + 轨迹类型）中，对轨迹类型的 K-1 个虚拟变量做联合 Wald 检验 |
| **可检验的零假设** | H0: β_trajectory_1 = β_trajectory_2 = ... = β_trajectory_{K-1} = 0 |
| **成功判据** | Wald 检验 p < 0.01；AUC(M3) - AUC(M0+BDM) 的 Delong p < 0.05；增量 AUC > 0.03 |
| **如果该主张失败** | 报告"行为截面BDM与行为序列轨迹等价——这说明信息生产的流水线不会因维度增加而变强" |

### 主张 A5：转折点与外生事件相关
**简述**：轨迹中的转变（即行为模式发生质变的时间点）不是随机的，而是与市场事件（牛熊转换、gas 对冲、协议变更）有关。

| 项目 | 内容 |
|------|------|
| **理论/文献支撑** | Elder (1998) 的"转折点"概念；Qin et al. (2021) — 清算机制与gas事件的交互；Sadeghi & Feinstein (2026) — 交易成本对清算行为的影响 |
| **技术操作** | 识别转折点 → 检验转折点前后2周内的外生事件频率是否超过偏差期 |
| **可检验的零假设** | H0: 转折点前后2周的外生事件频率 = 偏差期的频率 |
| **成功判据** | 费希尔精确检验 p < 0.05（至少一个事件类别） |
| **如果该主张失败** | 报告"转折点不是外生市场事件的功能——可能由内生机制生成" |

### 主张 A6 (RQ4)：轨迹类型可用于治理干预
**简述**：协议可以使用轨迹类型来识别高危借款人，主动调整清算阈值可以改善协议的总体福利。

| 项目 | 内容 |
|------|------|
| **理论/文献支撑** | Piquero (2008) — 轨迹类型以干预/政策导向；Pistor (2020) — 金融治理的编码化；Klages-Mundt (2023) — DeFi 中的最优协议参数设计 |
| **技术操作** | 用于治理模拟的预测模型 + 清算阈值调整模拟 + ΔW 的 bootstrap |
| **可检验的零假设** | H0: 模拟中 ΔW ≤ 0 |
| **成功判据** | 95% bootstrap 置信区间 ΔW > 0 |
| **如果该主张失败** | 报告"行为轨迹的预测力不足以产生正福利——但模型本身提供了一个可复用的框架" |

## 风险控制映射

| 风险 | 相应的缓解步骤 | 涉及的文献/方法 |
|------|--------------|-------------|
| 序列不可分型 | 转换为轨迹距离矩阵 + 核方法直接预测 | Wang et al. (2018) — DTW核；Bai et al. (2019) — entropic DTW核 |
| RAT无信用增量 | 接受并撰写"行为过程的线性压缩足够——序列没有额外信息"的经济解释 | Aisenbrey & Fasang (2010) — 提供了统计工具来支持"无差异"的结论 |
| 计算不可扩展 | 随机抽样 (10K) 或 DTW lower bound 近似 | Keogh's LB_Keogh 用于 DTW 的快速lower bound |
| 主动行为样本不足 | 回到V4 PoC判据——只有被动行为才考虑全方向拒绝 | V4 PoC 框架 |
| 聚类命名过于武断 | 采用"双向"方法——定量聚类 + 同时提供BDA的"聚类特征原型"（medoids），减少个人标注的武断 | Jain (2010) — 聚类后模型解释的多种方法 |

## 跨分支映射

| RAT 主张 | 与B(本体论)的关系 | 与C(HAM)的关系 | 与D(数据驱动)的关系 |
|----------|----------------|--------------|-----------------|
| 序列形态 > 截面偏差 | B 不会预设"偏差"——本体会将"序列形态"作为信息生产的一个输入；RAT直接生产这个输入 | C 会问"序列形态是否源于不同的行为策略类型"——两者完全兼容 | D 不需要任何理论——直接检验"有无形态"即可 |
| 多通道分析 | B 的本体可以是RAT多通道的知识表示——"行动"、"风险状态"和"风险态度"可以定义为本体中的类-关系 | C 的HAC会用多通道距离来定义一个"特征空间"，在这个空间里识别类型 | D 的因子分析等价于单通道特征分解——RAT是"多通道"，D是"因子" |
| 轨迹类型聚类 | B 会将这些类型作为本体的"实例"——"预防型"在DeFi信用本体中扮演什么角色？ | C 的风险在于：“轨迹类型"可能在C的框架中会被"行为策略类型"吞没——因为轨迹类型其实就是策略类型的可视化表示 | D 不需要聚类——如果BDM是因子，那"它是哪一类的特征"就没意义了 |
| 治理模拟 | B 提供了模拟的理论支柱——"哪种本体重排可以改善福利？" | C 提供了异质性支柱——并非所有类型都同等对待干预 | D 提供了纯经验——福利变化可能是正的也可能是负的——都是发现 |

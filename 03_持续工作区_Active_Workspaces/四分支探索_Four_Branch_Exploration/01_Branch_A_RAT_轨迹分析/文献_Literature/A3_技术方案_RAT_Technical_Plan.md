# Branch A 技术方案：序列分析与轨迹聚类的完整技术路线图

**版本**：v1.0 | **日期**：2026-07-08

---

## 技术方案概要

本技术方案覆盖 RAT 的五个技术层面：（1）数据流水线——从 Aave 交易日志到可分析的多通道序列；（2）序列距离计算——单通道 vs 多通道的最优匹配/DTW参数；（3）聚类与验证——从距离矩阵到可解释的轨迹类型；（4）预测建模——从轨迹类型到清算的概率；（5）因果推断框架——序列如何被用于外生事件的效果识别。

## 1. 数据流水线

### 1.1 输入数据

从 Dune Analytics / The Graph 查询以下原始表：

| 数据表 | 内容 | 关键字段 |
|--------|------|----------|
| `aave_v2_ethereum.Deposit` | 存款/加抵押事件 | user, reserve, amount_usd, block_time, txn_hash |
| `aave_v2_ethereum.Withdraw` | 取款/撤抵押事件 | user, reserve, amount_usd, block_time, txn_hash |
| `aave_v2_ethereum.Borrow` | 借款/增贷事件 | user, reserve, amount_usd, block_time, txn_hash |
| `aave_v2_ethereum.Repay` | 还款事件 | user, reserve, amount_usd, block_time, txn_hash |
| `aave_v2_ethereum.LiquidationCall` | 清算事件 | user, collateral_asset, debt_asset, amount_usd, block_time, txn_hash |
| `prices.usd` | 历史价格 | symbol, price, minute |

**需要自计算的关键变量**（不在原始交易日志中）：
- **Health Factor (HF)**：基于每个用户的 collateral（各储备的 USD 价值 × 各储备的清算阈值）和 debt（各 debt 储备的 USD 价值）在每个区块上的余额快照重新计算
  - 注意：Aave 链上 `getUserAccountData` 的返回值是在调用时刻原子的，但历史值需要在每个区块根据累积的 aToken 利息重新计算
- **主动 vs 被动行为分类**：通过交易的 `msg.sender` 字段区分
  - 主动行为 = msg.sender 是用户的 EOA 地址
  - 被动行为 = msg.sender 是合约地址（清算机器人、闪电贷合约等）

### 1.2 Spell 构造

**定义**：一个 spell 是"开始"(spell_start) 到"结束"(spell_end) 的有序序列，定义如下：

- **spell_start** = 用户在 Aave V2 Ethereum 上的第一次借款交易（Borrow 事件）的时刻
  - 仅考虑用户在 Aave 上的"首次开仓"spell（每个用户只保留第一个 spell，避免 spell 间的依赖）
  - 稳健性检验：包含所有 spell，并用 spell 顺序的固定效应控制
- **spell_end** = MIN(spell 对应的 debt 余额第一次归零, 用户的所有 deposit 被清算为零) 的时刻
  - 如果 spell 以"还清"结束 → 结局 = 0（非清算结束）
  - 如果 spell 以"被清算"结束 → 结局 = 1（清算结束）
  - 如果在数据截止日（2025-12-31 23:59 UTC）仍未结束 → "右删减"（censor），结局 = 0（censor）

**最小 spell 持续时间**：≥ 7 天（排除小于一周的极短期活跃交易）

### 1.3 序列化

对于每个 spell，构造时间等间距的序列：

**时间窗长度**：
- 主分析：周（calendar week）
- 清算前 30 天：日（捕获密集的行为转变）

**序列状态赋值（每个时间窗）**：

**通道 1：行动（Action）**——当窗内的主要净行为方向

| 状态 | 赋值条件 |
|------|----------|
| 加抵押 | Δ存款_usd > Δ取款_usd 且 Δ存款_usd - Δ取款_usd > 0.001 × total_deposit |
| 还款 | 非加抵押 且 Δ还款_usd > Δ借款_usd 且 Δ还款_usd - Δ借款_usd > 0.001 × total_debt |
| 增贷 | 非加抵押 且 Δ借款_usd > Δ还款_usd 且 Δ借款_usd - Δ还款_usd > 0.001 × total_debt |
| 撤抵押 | 非增贷 且 Δ取款_usd > Δ存款_usd 且 Δ取款_usd - Δ存款_usd > 0.001 × total_deposit |
| 无行动 | 其余情况（净变动 < 阈值的被动状态） |

**通道 2：健康因子区间（HF Zone）**——当窗的平均 HF 值

| 区间 | 边界 | 风险含义 |
|------|------|----------|
| 临界 | HF ∈ (1.00, 1.10] | 即期清算风险 |
| 高危 | HF ∈ (1.10, 1.20] | 近期清算风险 |
| 中危 | HF ∈ (1.20, 1.50] | 需要管理 |
| 安全 | HF ∈ (1.50, 2.00] | 适度缓冲 |
| 充裕 | HF > 2.00 | 大量缓冲 |

注意：由于 HF=1.0 以下通常立即被清算（除非 gas 太高），实际上 HF < 1.0 的窗口极少——这本身就是个信息——应该与"临界"区合并还是独立，取决于数据中 HF < 1.0 的窗口比例。

**通道 3：抵押品态度（Collateral Attitude）**——当窗内抵押品组合的净变化

| 状态 | 赋值条件 |
|------|----------|
| 增加波动资产 | Δ波动资产金额_usd > Δ稳定币金额_usd 且 Δ波动资产金额_usd > 0 |
| 增加稳定币 | Δ波动资产金额_usd < Δ稳定币金额_usd 且 Δ稳定币金额_usd > 0 |
| 无变化 | 其余情况 |

其中：波动资产 = ETH, WBTC, LINK, AAVE, etc.；稳定币 = USDC, USDT, DAI, etc.

## 2. 序列距离计算

### 2.1 替代成本矩阵的确定

**行动通道**（5×5 名义矩阵）：
根据过渡概率的替代成本——从训练数据中，对任意两个行动状态，计算在实际序列中处于状态 i 的下一窗口转换到状态 j 或 j 的下一窗口转换到 i 的联合概率。替代成本 = 2 - 2 × 联合概率。

**HF 通道**（5×5 有序矩阵）：
$ \text{cost}(i,j) = |i - j| $ 

保持 HF 区间的自然顺序——相邻区间（如"临界"和"高危"）的替代成本低，远距离区间（"临界"和"充裕"）的替代成本高。

**抵押品态度通道**（3×3 名义矩阵）：
- cost("增加波动资产", "增加稳定币") = 2（对立态度）
- cost("增加波动资产/增加稳定币", "无变化") = 1（与中性态度的距离）

### 2.2 Indel 成本

- 默认：各通道单位成本的 1/2
- 稳健性：单位成本的 1/10 和 1/1，检验 indel 的敏感度

### 2.3 多通道总距离

$$d_{\text{total}}(s_i, s_j) = w_A \cdot d_A + w_H \cdot d_H + w_C \cdot d_C$$

其中：
- $d_A, d_H, d_C$ 分别是行动、HF、抵押品态度通道的距离
- 主方案：$w_A = w_H = w_C = 1/3$
- 备选方案 1：行动通道权重更高 ($w_A = 0.5, w_H = 0.3, w_C = 0.2$)
- 备选方案 2：HF 通道权重更高 ($w_H = 0.5$，因为客观风险可能在交易行为之外独立预测清算)

### 2.4 DTW 备选路线

对于不等长 spell，DTW 的步骤：
1. 对各通道分别计算 DTW 对齐距离，使用无 window 约束（无 Sakoe-Chiba band）
2. 将三个通道的 DTW 距离标准化后（除各通道的最大距离），等权加总
3. 得到 n × n 对齐距离矩阵

**OM vs DTW 选择判据**：
- 如果 spell 长度的标准差/均值 < 0.3（序列长度相对均匀），OM 足够
- 否则使用 DTW

## 3. 聚类与验证

### 3.1 层次聚类

- **方法**：Ward's method（最小方差法），在平方欧几里得距离上最小化聚类内方差
- **R 库**：`TraMineR::seqdist()` 计算距离矩阵 → `fastcluster::hclust(method = "ward.D2")`
- **剪枝**：通过 dendrogram 剪枝到 K 个聚类

### 3.2 最佳聚类数的选择

| 指标 | 判据 | 阈值 |
|------|------|------|
| 轮廓系数 (ASW) | 最大化 | ASW > 0.5 可接受；> 0.7 强结构 |
| CH 伪 F | 最大化 | 选择 global 或 local 最大值 |
| 最小聚类规模 | — | 每个聚类 ≥ 5% 样本 |
| 实质可解释性 | 手动检查 | 聚类中心具有经济含义 |

**K 的选择策略**：通常选择 CH 统计量的 "elbow" 后的第一个局部最大值

### 3.3 聚类结构显著性检验

- **自助法检验**：在 spell 上做 1000 次自助法重抽样，对每个 bootstrap 样本计算三通道序列距离和所有 K 的聚类
- **检验**：真实 ASW 是否显著大于 bootsrap 分布的第 95 百分位数 → 如果大于，说明聚类结构是显著的，不是噪声的 artifact
- **补充检验** 用 PAM (Partitioning Around Medoids) 来取代层次聚类，检查方法独立性

### 3.4 聚类中心的可视化与命名

对于每一类别，绘制"聚类中心"——使用所有成员的序列状态的众数（mode）来构造一个"代表性序列"（medoid 意味着找一个真实的最中心的代表性序列，众数序列意味着最频繁的状态在每个位置）：

- **状态分布图（State Distribution Plot）**：三类通道的子图——每行是一个聚类，X 轴时间，Y 轴是状态的比例（用颜色块表示）
- **代表性的"序列索引图"（Sequence Index Plot, SIP）**：每个序列的甘特图——每行是一个 spell，X 轴时间，Y 轴用不同颜色表示不同的序列状态（行动通道为主）

聚类中心的命名应基于：
1. 行动通道的常见模式 （如"频繁加抵押"）
2. HF 通道的常见状态 （如"长期处于高危区"）
3. 抵押品态度的典型变化
4. 以及针对该聚类，清算结局的原始发生率

## 4. 信用预测建模

### 4.1 赛马设计

对清算结局（1=清算，0=censor/还清）拟合四个逻辑回归：

| 模型 | 特征 |
|------|------|
| M0 | 传统风险：HF_min（spell内最低HF）、HF_mean（spell内平均HF）、HF_sd（spell内HF波动性）、collat_ratio_mean、debt_to_deposit_ratio |
| M1 | M0 + 五个BDM维度：补救超配度、参考点跳变度、抵押品切换方向、清算后恢复模式、闪电贷非行动 |
| M2 | M0 + 轨迹类型：K 个虚拟变量（轨迹类型1 到 K-1，K 是参照类） |
| M3 | M1 + M2：所有变量（检验BDM和轨迹类型哪个更重要） |

### 4.2 增量预测力的检验

- **主要检验**：DeLong 检验比较 AUC(M2) vs AUC(M0)
- **次要检验**：DeLong 检验比较 AUC(M3) vs AUC(M1)（BDM + 轨迹类型 vs BDM 单独）
- **似然比检验**：M2 的似然值与 M0 的似然值之比 = 2×(LL(M2) - LL(M0)) ~ χ² (df = K-1，即新增参数的个数)
- **Brier 评分**：M0 vs M2 的分数差，低者更好

### 4.3 生存分析框架

由于"未被清算的观察"包括真实存活（可能未来被清算）和右删减，逻辑回归实际上是有偏的（它把右删减当作结局=0），标准的替代是 Cox 比例风险模型：

- **因变量**：时间到清算（days_to_liquidation）
- **删减变量**：censor = 1 如果 spell 持续到数据截止日未被清算
- **协变量**：与 M2 相同 + 时变协变量（周级 HF）
- **检验**：log-rank 检验 K 个轨迹类型的生存曲线是否相同

### 4.4 类别级别的特征重要性

- 用 SHAP（SHapley Additive exPlanations）对最终 XGBoost/LightGBM 模型分解每个特征对每个预测的贡献
- 具体关注：哪个通道（行动 vs HF vs 抵押品态度）的轨迹特征对最终预测贡献最大？
- 在 K 个虚拟变量中，哪些类型的正向预测（增加清算风险）和负向预测（降低清算风险）的 SHAP 值方向与预期一致？

## 5. 因果推断与治理模拟

### 5.1 转折点分析（RQ3）

**定义**：轨迹转折点 = 在序列聚类后，某个 spell 的序列与该聚类的中心序列在时间 t 的偏离度（局部距离）的导数达到最大的时刻。

**操作**：
1. 对于每个 spell，计算其与所属聚类中心的"滑动窗口距离"——每个窗口 t 的三通道平均距离（不使用 indel，只考虑该窗口的对齐）
2. 找到距离突然增大的窗口（偏离中心序列最远的时刻）——这就是候选转折点
3. 检验转折点前后的外生事件频率：在转折点前 2 周内，是否存在以下事件？
   - ETH 日回报率超出 ±2 标准差
   - gas 价格超出 +2 标准差
   - Aave 协议参数变更（如新的清算阈值、增加/移除抵押品等）
   - 重大策略公告或新闻冲击（如果可获取）

### 5.2 治理干预模拟（RQ4）

**模拟设置**：
1. 用 M2（M0 + 轨迹类型）训练清算预测模型
2. 对测试集中，识别出预测清算概率最高的 20% spell（高危组）
3. 模拟治理策略："如果协议将高危组的清算阈值从 HF=1.0 提高到 HF=1.05"（即如果 HF 降至 1.05 就引发部分清算）
4. 计算期望福利变化 ΔW = (坏账减少的金额) - (被清算的用户多付的金额 + 协议执行费用)

**蒙特卡洛**：用自助法（bootstrapped spells）生成 1000 个可能的坏账分布，计算 ΔW 的 95% 置信区间。

## 7. 预期结果

### 7.1 如果一切顺利（正结果）

- 在 Aave V2 上识别出 5-7 个高度可解释的轨迹类型
- 其中 "慢性冒险型" 和 "无为型" 的清算率显著高于其他类型
- "预防型" 的清算率显著低于基准
- 轨迹类型的增量 AUC（vs 纯 HF 动态）0.05-0.10
- 从 Aave 到 Compound 的迁移中，至少 3 个同样识别的轨迹类型的信用预测方向一致

### 7.2 如果部分失败

- 可以识别出轨迹类型（轮廓系数 > 0.5），但轨迹类型不预测清算 → 报告"行为过程的多变性不意味着信用信号——借款人的行为轨迹有结构，但在信用判断中没有价值"（具有相同的科学价值）
- 序列不能分型（轮廓系数 < 0.2） → 报告"DeFi 借贷行为没有稳定可分的序列形态——行为是高斯噪声的过程"（也成立）

## 8. 敏感性与稳健性检验

| 维度 | 主方案 | 备选方案 | 检验什么 |
|------|--------|----------|----------|
| 距离度量 | 多通道DTW | 多通道OM | DTW 的对齐假设是否影响结果？ |
| 替代成本 | 过渡概率基础成本 | 统一成本（=1） | 替代成本对聚类结果的影响？ |
| 聚类算法 | 层次 Ward's | K-medoids (PAM) | Ward's 的直径对小聚类的倾向？ |
| 状态表示 | 5 + 5 + 3 = 75 个三通道联合状态 | 三个独立维度 | 联合表示比分别表示更好吗？ |
| 时间粒度 | 周 | 两周 / 天 | 窗口粒度的选择是任意的吗？ |
| 通道权重 | 等权 (1/3, 1/3, 1/3) | (1/2, 1/4, 1/4) 等 | 多通道距离的构造是否对权重敏感？ |
| 样本 | Aave V2 | Compound V2 | 外部效度 |
| 协变量 | 无 | 跨协议、钱包年龄 | 控制混杂因素 |

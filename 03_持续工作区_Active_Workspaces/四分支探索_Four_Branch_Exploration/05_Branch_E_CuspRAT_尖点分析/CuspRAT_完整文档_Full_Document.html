Branch E：Cusp Catastrophe RAT — 四路径类型与动力系统框架

版本：v1.0 | 日期：2026-07-08 | 性质：独立博士论文候选方向 | 与 Branch A（序列分析RAT）的关系：互补，非替代

摘要

现有 Branch A（序列分析RAT）从社会学序列分析传统出发，通过 OM/DTW + 聚类识别轨迹类型。该框架的方法是严谨的，但其"数据驱动的聚类"逻辑存在一个理论缺口：轨迹类型为什么是这些而不是那些？如果换一组借款人，轨迹类型会改变吗？ 方向一升级版通过引入Cusp Catastrophe 模型（Thom, 1975）和动力系统理论（dynamical systems theory），为 RAT 提供一个生成性的数学模型——不是从数据中聚类发现轨迹类型，而是从模型的几何结构导出轨迹类型。四路径类型（早期出清型、阈值跳变型、持续加杠杆型、惰性漂移型）是从 Cusp 控制曲面的几何性质中自然产生的。

1. 核心直觉：为什么Cusp模型比序列分析更精确

1.1 序列分析 RAT 的局限

序列分析RAT（A1-A4）的强大之处在于描述——它能发现数据中存在的结构。但它的理论中的因果机制是薄弱的： - 为什么借款人会展现出某种轨迹形态？ - 轨迹类型是性格特质（stable trait）还是状态依赖（state-dependent）？ - 如果市场条件改变，轨迹类型如何发生变化？

这些问题序列分析只能回答"存在"而不能回答"为什么"。

1.2 Cusp Catastrophe 模型的核心优势

Cusp catastrophe model 是 René Thom (1975) 提出的七个基本突变模型中最常用、最直观的一个。它的数学形式简单但行为复杂：

模型的几何结构：

- 一个行为变量 $y$：借款人的风险调整行为强度（从"不作为"到"紧急补仓"的连续谱系） - 两个控制变量： - $\alpha$：不对称因子（normal factor）——HF 的绝对水平，决定行为位于曲面的哪个"区域" - $\beta$：分岔因子（splitting factor）——HF 下降速度 + 抵押品波动率，决定行为曲面是否存在"折叠"（fold）

关键行为特征：

- 当 $\beta < 0$ 时，控制曲面平滑，行为随 HF 下降而线性增加——这是标准的前景理论预测 - 当 $\beta > 0$ 时，曲面存在一个不可达区域（折叠），两个稳定平衡态之间发生非连续跳变——这是 Cusp 的独特预测：行为在某一临界点上发生突跳（catastrophic jump），从"低行为强度"直接跳变到"高行为强度"

在 DeFi 上下文中的含义：

- $\beta > 0$ 的情境对应"抵押品高波动 + HF 快速下降"——这正是市场恐慌的典型场景 - Cusp 模型预测：在恐慌市场中，借款人的风险调整行为不应该是线性的——它在某个临界 HF 值的附近会发生跳变 - 这种跳变模式与金融数据中常见的"非线性"现象相吻合——但传统行为经济学模型（前景理论）无法自然产生这种非连续性

1.3 与前景理论的本质区别

维度前景理论Cusp RAT
行为假设损失厌恶（$\lambda > 1$）导致对风险下倾的反应行为反应是一个动力系统——HF（$\alpha$）+ 变量（$\beta$）共同决定反应曲面的形状
非线性来源参考点效应——在参考点附近价值函数更陡几何上——控制曲面中的折叠导致非连续跳变
模型性质描述性（descriptive）：描述为什么反应不对称生成性（generative）：描述怎么反应的，并从几何结构中产生预测
实证预测反应在 HF<1.1 时尤其强反应在 HF 进入折叠区间的瞬间发生跳变——不连续
Cusp RAT 不推翻前景理论——它包含前景理论作为特殊情形（当 $\beta < 0$ 或当折叠尚未触达时）。 这意味着 Cusp RAT 是一个更具一般性的理论框架，前景理论是其子集。

2. 四路径类型：从Cusp几何结构导出的自然类型

Cusp 模型的控制曲面自然地将行为空间划分为四个区域。这四个区域不依赖于聚类，而是由模型几何导出的穷举的类型体系：

类型一：早期出清型（Early Clearance）—— 对应于低$\beta$的线性响应区域

HF特征：HF 刚跌至 1.5 就大规模补仓 Cusp 对应的几何位置：行为变量 $y$ 位于控制曲面的下层稳定叶（lower stable sheet）的左侧边缘——在折叠之前就已完成响应 行为特征：

- 在 HF 仍然较高时（>1.3）就开始系统性加抵押 - HF 的下降与加抵押行为几乎呈线性关系 - 反应幅度大但反应时机早——在折叠到达之前就过渡到高行为强度状态 - 从不在 HF<1.1 时紧急操作——因为"紧急"的需求已在早期被消解

信用含义：稳健者。这些借款人将"预防性仓位管理"作为一种主动策略。他们不是在"逃避损失"（损失厌恶）——而是在策略性地将 HF 维持在高位以满足再投资或杠杆限制。 在V4框架中的映射：这些借款人表现出高 BDM-补救超配度，但超配度的来源是早期预防性行为，而非恐慌驱动的紧急补仓。

类型二：阈值跳变型（Threshold Jump）—— 对应于Cusp的非连续跳变

HF特征：HF 从 1.3 骤降至 1.05 时才紧急操作 Cusp 对应的几何位置：轨迹从控制曲面的上层稳定叶（upper stable sheet）穿过折叠线（fold line），发生一次非连续跳变（jump）——$y$ 从低值瞬间跃升至高值 行为特征：

- 在 HF 从 1.8 到 1.3 的区间内，反应性行为强度极低 - 当 HF 穿越某个阈值（通常是 1.1-1.05）时，行为强度不连续地跳升 - 跳变的幅度取决于 HF 下降速率的快慢 - 跳变后的行为模式是"全量响应"——一次性大量加抵押以将 HF 推回安全区间

信用含义：恐慌驱动。这些借款人并非没有能力管理仓位——他们有足够的抵押品来加，但他们没有在日常中主动监控头寸。这种行为模式的根本驱动力是疏忽而非风险的主动寻求——但准备金不足时可能无法完成跳变（即被清算）。 与前景理论的差异化预测：

- 前景理论预测：借贷人越接近 HF=1，反应越强（参考点效应 + 损失厌恶） - Cusp 预测：反应不仅随 HF 接近 1 变强——它在某个临界值不连续地跳变。连续模型无法捕获这一点

类型三：持续加杠杆型（Continuous Leverage-Taking）—— 对应于Cusp控制曲面上的持续下降

HF特征：HF 下降过程中不断增借 Cusp 对应的几何位置：轨迹在控制曲面上持续向下移动——不仅没有跳变，反而继续远离高行为强度区域 行为特征：

- 在 HF 下降期间，借款人增加杠杆而非降低——从抵押品中借款更多 - 行为的方向性（direction）与 Cusp 模型的线性预期相反——模型预测 HF↓ 应导致加抵押↑，但观测结果是 HF↓ 导致借款↑ - 这种行为不能通过 Cusp 模型中的"正常"参数值（$\alpha, \beta$）解释——需要引入一个新的不对称性：借款人对 HF 下降的反应符号反转

信用含义：可能性偏好（probability preference）。这些借款人可能是：

- 赌博型：将杠杆视为"翻本"的工具（disposition effect 在 DeFi 中的表现） - 套利型：在进行某种市场中性策略（如对冲），需要借款来保持 delta 中性 - 信息驱动型：根据某个信号认为市场价格会回升，因此不应该平仓

与异质预期（Branch C）的连接：持续加杠杆型对应 Branch C 中的"损失追求者（Loss-Chaser）"类型——在损失域中继续冒险。Cusp RAT 解释"为什么"这种类型存在：借款人的控制变量（$\alpha, \beta$）使行为曲面的形状发生变化——原来应该起稳定作用的机制被抑制了。

类型四：惰性漂移型（Inertial Drift）—— 对应于Cusp折叠区域内的"挂起"状态

HF特征：长期不操作直到被清算 Cusp 对应的几何位置：轨迹在折叠区域内但不跳变——原因可能是控制变量 $\beta$ 的波动率不足，以至于不能将行为强度推过折叠 行为特征：

- 借款人在数周甚至数月内无任何主动行为 - HF 因市场波动而自然下降——没有主动加杠杆，纯粹是抵押品价值侵蚀 - 清算不是由于"冒险"而是由于"疏忽"——借款人可能已经丢失了私钥、忘记了头寸存在、或完全不用这个地址 - 当联系人试图联系时（如 Etherscan 上的消息），无响应

信用含义：信息不完全或完全疏忽。这些借款人不是"坏借款人"——他们只是不存在于 DeFi 中作为监控实体。信用判断在这种情况下面临的根本性限制是：DeFi 不能强制关键信息的更新，只能等待行为。 实证可操作化：

- 行为变量 $y$ = 0 的连续期数 > N 周（$N=4$ 作为诊断阈值） - 结合"地址活跃度"特征——如果该地址在 DeFi 之外有其他交互（如发送 ETH），惰性漂移更可能是疏忽导致，而非真正遗忘

3. 动力系统框架：Cusp模型的形式化

3.1 势函数

Cusp 行为的背后是一个双势的势函数：

$$V(y; \alpha, \beta) = \frac{1}{4}y^4 + \frac{1}{2}\beta y^2 + \alpha y$$

其中： - $y$ 是风险调整行为强度的连续变量 - $\alpha$ 是对称断裂参数（HF 水平的线性函数） - $\beta$ 是分岔参数（HF 下降速度 + 抵押品波动率的函数）

势函数具有以下性质： - 当 $27\alpha^2 + 4\beta^3 < 0$ 时，势函数有两个稳定平衡点（双稳态）——行为可以在"高行为强度"和"低行为强度"之间选择 - 在折叠线上（$27\alpha^2 + 4\beta^3 = 0$），这两个平衡态合为一个——系统变得对扰动极敏感 - 在折叠区域外（$27\alpha^2 + 4\beta^3 > 0$），只有一个稳定平衡点——行为随 $\alpha, \beta$ 平滑变化

3.2 平衡面方程

在准静态近似下（假设行为比控制变量变化得更快），$y$ 调整到平衡点满足：

$$\frac{\partial V}{\partial y} = y^3 + \beta y + \alpha = 0$$

这是一个三次方程。当判别式 $\Delta = (\alpha/2)^2 + (\beta/3)^3 > 0$ 时，只有一个实根（单稳态）。当 $\Delta < 0$ 时，有三个实根——两个稳定，一个不稳定。

在 DeFi 中的翻译：

- $\Delta > 0$：市场平静期（HF 缓慢变化、波动低）→ 行为平滑 → 早期出清型或惰性漂移型 - $\Delta < 0$：市场压力期（HF 快速下降、波动高）→ 行为双稳态 → 阈值跳变型

3.3 控制参数的微观基础

$\alpha$ 和 $\beta$ 不是"自由参数"——它们可以从借款人的持仓特征和市场状态中构造：

- $\alpha_i(t) = \gamma_0 + \gamma_1 \cdot HF_i(t) + \gamma_2 \cdot \Delta HF_i(t)$ - $\beta_i(t) = \delta_0 + \delta_1 \cdot \sigma_c(t) + \delta_2 \cdot |\Delta HF_i(t)|$

其中： - $\sigma_c(t)$ 是抵押品组合的波动率 - $\Delta HF_i(t)$ 是 HF 的即时变化率

这些参数可以通过面板数据估计——为每个借款人在每个时间点估计其所在的 Cusp 区域。

4. 与V4的衔接：RQ1b的设计

4.1 保留RQ1的静态前景理论检验

V4 的核心 RQ1 保持不变： - RQ1（静态）：DeFi 借款人是否表现出前景理论预测的行为模式（损失厌恶、参考点效应、递减敏感性）？

方向一升级版不推翻这个检验。如果 RQ1 通过，它为 V4 提供了静态的行为基础。如果 RQ1 不通过，方向一升级版提供了备选解释——不是行为不偏离理性，而是偏离采用了一种非线性的、非连续的形式。

4.2 新增RQ1b：动力系统扩展

RQ1b（动态扩展）：在控制了前景理论的静态预测后，借款人的 Cusp 轨迹类型是否能解释 HF 动态和 BDM 无法解释的清算风险方差？

具体操作： 1. 为每个借款人估计 Cusp 模型（$y_i(t), \alpha_i(t), \beta_i(t)$ 的参数） 2. 识别每个借款人在每次状态（spell）中的轨迹类型（早期出清/阈值跳变/持续加杠杆/惰性漂移） 3. 在清算预测模型中进行层次化赛马： - M0：HF 动态特征 - M1：M0 + BDM 五维度（V4 的静态偏差指数） - M2：M1 + 前景理论参数（$\lambda$, 参考点等） - M_RAT：M0 + Cusp 路径类型虚拟变量 - M_full：M1 + M2 + M_RAT

关键检验：M_RAT 的 $\Delta$AUC 是否 > 0，并且 M_RAT 系数的符号是否与 Cusp 预测一致？

5. 实证操作：如何估计Cusp模型

5.1 数据需求

与序列分析RAT相同的基础数据：Aave V2/Compound 的完整交互记录。额外需要： - 每个地址每个时间点（小时或天级别）的 HF 值 - 抵押品组合的时变波动率（可从去中心化交易所的价格源计算） - 主动行为的时间点（加抵押、还款、增贷、取款的精确时间戳）

5.2 估计策略

阶段一：降维

- 对每个借款人行为计算行为强度 $y_i(t)$：标准化为[0,1]的主动交易强度（数量×频率）

阶段二：参数估计

- 对于每个借款人的每个 spell，展演非线性回归： $$y_i(t) = g(\alpha_i(t), \beta_i(t); \theta) + \epsilon_{it}$$ 其中 $g$ 是 Cusp 密度函数（隐式定义，因为 $y$ 受制于平衡面方程）

- 估计方法：最大似然法（Cobb, 1981）或最小绝对偏差法（Guastello, 1982）

阶段三：类型分配

- 根据估计的 $\alpha_i, \beta_i$ 路径在控制曲面上的位置，分配每个 spell 到四种类型之一 - 不使用聚类——类型从模型几何中导出

5.3 可选的简化方法（如果全解析估计不可行）

Cusp 的全极大似然估计对数据密度要求极高。一个更易行且仍能捕获核心动态的简化方法是：

- 不估计完整的 Cusp 模型（复杂的非线性似然） - 而是：对每个借款人计算"HF-行为"函数的局部曲率（可用局部多项式回归） - 通过曲率分布的多峰性（bimodality）来诊断 Cusp 行为：如果在控制曲面的某些区域观测到"双稳态"（某些借款人行为高，某些低，没有中间地带），这是 Cusp 几何存在性的强证据

6. 理论支撑：Cusp在社会科学中的应用先例

6.1 组织行为学中的Cusp模型

Cusp 已被成功应用于社会科学的多个领域： - 工作态度与行为：Sheridan (1985) 使用 Cusp 模型解释护士流失——工作满意度的中小变化可以导致离职倾向的急剧跳变，而线性模型无法捕获 - 消费者行为：Oliva, Oliver & MacMillan (1992) 将 Cusp 应用于品牌切换——小价格下降不会马上引发品牌切换，但当价格下降到某个阈值时，行为发生灾难性跳变 - 金融恐慌：Zeeman (1974) 的开创性工作——证券市场中的恐慌与贪婪可由 Cusp 模型描述

6.2 与DeFi行为的类比

DeFi 借款人与上述模型存在关键的结构性类比： - 护士离职 ↔ 借款人不补救→被清算：线性模型预测满足度每降低一个单位，离职概率增加一个常数。Cusp 预测存在一个"不快也不Loyal"的双稳态区间。类比——HF 在 1.05-1.15 时，借款人处于双稳态：可去可不去。 - 品牌切换 ↔ 从 Aave 迁移到 Compound：当 Aave 的提供利率下降一点时，线性模型预测少量用户流失。Cusp 预测：没有大幅变化直到某个阈值，然后是灾难性流出。 - 金融恐慌 ↔ DeFi 银行为何需要"保险"：恐慌不是线性的——它是在某个信息触发下由 stasis 跳转到 panic。传统风险指标（线性预测）会低估极端事件的风险。

6.3 相对于前景理论的认识论优势

Cusp RAT 不要求你选择"损失域还是风险域"——前景理论关心的是行为对价值的响应。Cusp RAT 关心的是行为作为控制参数的函数的几何结构。这个区别似乎微妙，但却是根本的：前者假设了"一个价值函数"的普遍性；后者只假设"一个动力系统的存在"，而其参数可以是异质的（连接 Branch C）。

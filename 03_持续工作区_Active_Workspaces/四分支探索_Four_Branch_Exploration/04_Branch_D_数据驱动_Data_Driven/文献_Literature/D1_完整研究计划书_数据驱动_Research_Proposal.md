# Branch D：数据驱动最小可发表单元 — 完整研究计划书

**版本**：v1.0 | **日期**：2026-07-08 | **性质**：博士论文候选方向 / 安全网方案

---

## 摘要

Branch D 是四个方向中唯一一个在理论不可知条件下运作的方案。它不预设前景理论（V4）、不依赖序列分析的方法迁移（Branch A）、不需要本体的概念框架（Branch B）、也不要求 HAM 的演化假设（Branch C）。它只问一个纯粹的经验问题：**DeFi 借款人的链上行为模式是否能够预测清算——不管原因是什么？** 研究通过无监督行为特征提取（PCA/因子分析）、赛马预测设计和治理模拟，提供一个完整的"发现-验证"管道。最重要的是：无论行为信号**存在**还是**不存在**，论文都能提供科学上可发表的结果——正结果证明行为信息的生产力；负结果反证 DeFi 透明性不等于信用透明性。这是为博士论文提供的最终安全网——当所有其他理论方向都失败时，D 仍保证可发表。

## 1. 问题陈述

### 1.1 理论上中立的信用预测

在 V4 中，行为被理论所约束：如果前景理论成立，那么 X 指标应该预测清算。如果前景理论不成立，指标可能仍然预测清算——但它们被赋予的"损失厌恶"解释就崩溃了。

Branch D 拒绝这种"预测→解释"的自上而下的推理结构。它只问：
1. **存在**：DeFi 借款人的行为特征空间是否有结构？（因子分析会发现什么？）
2. **信息**：这些行为特征是否比传统风险指标更好地预测清算？（赛马）
3. **跨域**：预测关系在跨协议和跨时间上有多稳健？（外部效度）
4. **福利**：如果将这些特征用于协议级的风险治理，福利是否会改善？（治理模拟）

如果对这四个问题的回答全是"否"——如果行为特征没有结构、不预测清算、不能跨协议泛化——Branch D 仍有发表权：**"DeFi 链上行为不包含信用信号的实证证据"** 是一篇重要的**否定结果论文**（经充分验证后）。

### 1.2 核心研究问题

1. **RQ1（行为模式存在性）**：DeFi 借款人的行为特征空间是否有统计上清楚的、可解释的结构？
2. **RQ2（行为模式的信息内容）**：从行为特征模式提取的因子是否比纯 HF 更好预测清算？（不管原因）
3. **RQ3（跨协议外部效度）**：在 Aave 上学到的行为模式是否可以迁移到 Compound 而后验预测力不显著退化？
4. **RQ4（治理福利）**：如果协议使用行为预测来风险分层，总的福利是否显著改善？

## 2. 理论框架（最小集）

### 2.1 三种经验假设

| 假设 | 内容 | 可被证伪的方法 |
|------|------|-------------|
| **E1：行为梯度** | 借款人主动行为随 HF 变化（至少部分借款人）——无论方向 | 检验每个行为类型的方向：加抵押随 HF↓ 而增加？（多数——可能是防御型）还是随 HF↓ 而减少？（少数——可能是追求风险型） |
| **E2：行为惯性与信用** | 控制了 HF 动态后，行为的历史惯性（过去的行为预测当前行为，超出理性解释的部分）包含信用信息 | 行为惯性 = 当前行为 − 最佳理性预测（基于当前 HF 和一系列控制因素）——在训练集外检验该残差的预测力 |
| **E3：增量信息** | 行为特征集合的信用信息不是旧信息的线性编码 | 标准赛马：行为特征的预测力是否优于纯 HF + 活跃度的特征 |

### 2.2 与 V4 的关系

- **保留**：全部数据基础设施（Aave/Compound 查询、HF 自计算、主动/被动分类树）、PoC 验证项（Safe 占比、闪电贷窗口）、赛马设计精神、决策锚ΔW。
- **砍掉**：前景理论 $\lambda$、$v(x)$、$\pi(p)$ 全部三个参数；关于 H1a/H1b/H1c 的具体预测；全部前景理论相关文献。
- **重定位**：BDM 从"服务于理论检验的构念"变为"数据驱动的行为特征集合"。

## 3. 操作化方案

### 3.1 三层经验分析

**第一层：行为模式识别（无监督学习）**

1. 从每个 spell（用户-开仓周期）提取全部行为特征：
   - HF 弹性（$\log$ 加抵押 ~ $\log$ HF）
   - 行为的不对称性（对 HF 下降的反应 vs. HF 上升的反应比）
   - 跨时间和跨交易量的集中度
   - 清算后可量化的恢复行为

2. 对特征空间进行 PCA/因子分析 → 提取 3-5 个"行为因子"

3. 描述这些因子的统计分布：是单峰（一个总体）还是多峰（多个子类型）？这与 Branch C 的核心——"是否异质性存在"——间接对话。

**第二层：信用预测（赛马设计）**

使用逻辑回归或 Cox 比例风险模型，赛马：

| 模型 | 特征 |
|------|------|
| M0 | 纯 HF + 抵押率（传统风险） |
| M1 | M0 + BDM（行为特征基线） |
| M2 | M0 + 行为因子（从第一层提取的）— **主判定** |
| M3 | M0 + BDM + 行为因子（全模型） |

**关键检验**：M2 是否显著优于 M0？（Brier Score 降低或 AUC 提高）这决定了"行为是否提供增量信息"。

**第三层：治理模拟**

1. 用 M2 的预测模型将用户分为三个风险层：低（预测清算概率 < 0.05）中（0.05-0.15）高（> 0.15）
2. 模拟治理策略："对于高风险用户，将清算阈值从 1.0 提高到 1.05" → 提前清算一些仓位
3. 计算 ΔW = 坏账减少 − 额外的费用支出
   - 坏账减少：被提前清算的多出的用户 = 原本不会留下坏账的
   - 额外的费用支出：被清算的用户多付的钱（比正常的归还清还多了 5% 的损失分摊）

### 3.2 方法考虑

- **主模型**：逻辑回归（最透明、可解释性最强）
- **辅助模型**（特征重要性分解）：LightGBM + SHAP
- **时间序列交叉验证**（非随机交叉验证——训练和测试集必须来自不同的日历窗口）
- **灾难性遗忘检验**：用牛市中训练的系数在熊市样本中测试——看看行为-信用的关系如何恶化（外部效度检验）

## 4. 失败或"中立"结果的发表策略

D 的一个基本哲学是：**科学从新的否定结果中学到的东西不亚于从肯定结果中学到的**。以下是可能结果的光谱：

| 结果 | 发表机会 | 论文标题举例 |
|------|---------|-----------|
| 正结果：行为因子 → 更好的预测 | 高 — 经典的"发现新信号"的论文 | "Do On-Chain Behavioral Patterns Predict DeFi Liquidations?" |
| 行为因子预测，但不是增量 | 中 — 论文仍成立，但splash较小 | "Behavioral Information in DeFi Loans: A Confirmatory Study" |
| 无预测力 | 中 — 重要的否定结果 | "The Limits of Chain-Transparency: No Evidence of Behavioral Credit Signals in DeFi" |
| 预测从 Aave 到 Compound 不推广 | 中低 — 协议特化的有趣报告 | "Protocol-Specificity of DeFi Lending Behaviors" |
| 行为稳定但不预测 | 中 — 关于"为什么行为有组织但不提供信用信息"的讨论 | "Behavioral Structure without Credit Content in DeFi" |

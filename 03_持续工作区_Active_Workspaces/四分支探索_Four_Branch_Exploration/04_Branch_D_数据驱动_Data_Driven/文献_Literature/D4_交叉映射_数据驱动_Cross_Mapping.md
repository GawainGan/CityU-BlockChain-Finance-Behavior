# Branch D 理论-技术-主张交叉映射表

**版本**：v1.0 | **日期**：2026-07-08

## 核心主张映射

### 主张 D1：DeFi 行为特征空间有可解释的结构
**简述**：借款人的多种行为指标不是独立的——它们聚集到少数潜在行为因子上。

| 项目 | 内容 |
|------|------|
| **文献支撑** | Hamermesh (2000) — 在理论之前先指出存在有结构的事实是合法的；Breiman (2001) — 预测精度的提高确认了结构 |
| **技术操作** | 在 30-50 个行为指标上做因子分析（或 PCA） |
| **可检验的零假设** | H0: 因子前 3 的特征值 ≤ 随机数据中的预期特征值（即没有因子结构） |
| **成功判据** | 通过平行分析和 scree plot 至少识别出 3 个因子（每个有 ≥ 3 个高负载的特征） |

### 主张 D2：行为因子预测清算（增量信息）
**简述**：行为轮廓提供了超出传统金融指标的信息，改善了清算预测力。

| 项目 | 内容 |
|------|------|
| **文献支撑** | Ghosh et al. (2024) — 链上信贷评分的基线；DeLong et al. (1988) — 比较 AUC 的统计检验 |
| **技术操作** | 赛马：M2 (M0 + 行为因子) vs M0 (仅传统金融指标)，用 DeLong 检验 |
| **可检验的零假设** | H0: AUC(M2) ≤ AUC(M0) |
| **成功判据** | DeLong 检验单侧 p < 0.05 |
| **如果失败（p ≥ 0.05）** | 报告："没有证据表明 DeFi 的行为特征有预测清算的力量"（否定结果论文） |

### 主张 D3：跨协议外部效度
**简述**：在 Aave 上发现的预测关系在应用到 Compound 时保持稳健。

| 项目 | 内容 |
|------|------|
| **文献支撑** | Christensen & Miguel (2018) — 透明性和可复制性是经验研究的核心 |
| **技术操作** | 在 Aave 上训练 M2 模型，在 Compound 上测试 AUROC；比较性能是否恶化 |
| **可检验的零假设** | H0: AUC(Compound Test) ≤ 0.5（即不比随机好）|
| **成功判据** | AUC ≥ 0.60；系数方向一致 |

### 主张 D4：治理福利为正
**简述**：用行为轮廓进行风险分层，可以改善协议的总体福利。

| 项目 | 内容 |
|------|------|
| **文献支撑** | 无需特定理论——这是对 M2 的应用 |
| **技术操作** | 使用 M2 预测，将用户分层；模拟将高风险用户的清算阈值提高的影响；用 bootstrap 推断得出 ΔW |
| **可检验的零假设** | H0: ΔW ≤ 0（更高的清算阈值没有改善福利） |
| **成功判据** | 95% bootstrap 置信区间 [?2.5%, ?97.5%] > 0 |

## 风险控制映射

| 风险 | 缓解 |
|------|------|
| 行为因子无解释性 | 给因子一个尝试性的标签，同时报告最佳负载中的前 5 个特征 |
| 行为因子不预测清算 | 反馈到第一层——尝试非线性（XGBoost）来看看是否有隐藏的结构（负结果） |
| 跨协议 AUC 不显著 | 讨论协议特有的因素（gas 模型、抵押品种类）——这仍是一篇论文 |
| ΔW < 0（负福利） | 警告不要基于行为数据进行干预——"治理模型还没有为行为特征准备好" |

## 跨分支映射

| D 的主张 | 与 A (RAT) 的关系 | 与 B (本体) 的关系 | 与 C (HAM) 的关系 |
|----------|-----------------|---------------------|---------------------|
| 行为结构存在 | D 发现有结构，A 研究这结构的轨迹形式——两者可以互相检验！| B 会说"结构是本体造成的——如果没有一个分类镜头（本体），原始数据中根本找不到结构" | C 会说"结构的成因是什么？——因为存在潜在的异质性类型" |
| 行为因子的预测力 | D 将"增量信息"报告为一个事实；A 给出**为什么**—因为轨迹形态 | B 给出**为什么**—因为信息生产框架折射出的信号 | C 给出**为什么**—因为不同类型的行为因素的混合意味着不同的结果 |
| 跨协议效度 | D 作外部效度；A 也这样做但用序列形态；且 A 更挑剔（序列形状可能协议特化）| B 用跨协议的本体推理（债务能力vs支付意愿）| C 说类型分布是协议特化的（哈耶克式的） |
| 治理模拟 | D 给出一个抽象的基线（分层后的福利变化） | B 将模拟框架化为"用信用本体重排风险" | A 将刺激框架化为"如果我们将属于慢性风险的轨迹类型与合理类型的协议设计区分开" |

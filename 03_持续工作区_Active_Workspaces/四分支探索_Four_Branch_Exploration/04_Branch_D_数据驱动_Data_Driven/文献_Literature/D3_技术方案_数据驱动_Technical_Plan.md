# Branch D 技术方案：因子分析与赛马设计

**版本**：v1.0 | **日期**：2026-07-08

---

## 1. 数据准备

与其他分支共享数据基础设施。使用与 Branch A/C 相同的 user-spell 或 user-month 数据。

**核心行为特征集合（30-50个特征）**：

| 特征类别 | 特征举例 | D 中的角色 |
|----------|---------|-----------|
| HF 弹性 | 对 ΔHF 的行为反应（β） | 从E1派生 |
| 不对称性 | 行为对 HF↓ 的反应 / 行为对 HF↑ 的反应比率 | 这是 BDM"补救超配度"的特征对等物 |
| 时间集中度 | 交易发生的天/周/月的 Gini 系数（0=平铺，1=全部集中在一个瞬间） | 一个完全的非理论特征 |
| 市场行为 | 在市场上涨/下跌的日平均 Δ 借款 比率 | 市场择时 |
| 恢复后 | 清算后 30 天内的行为差异 | 恢复模式 |
| 协议复杂度 | 与之交互的唯一协议数（Aave + 其他） | 复杂性/丰富性 |
| 跨仓行为 | 同时拥有的仓位数的均值/方差 | 分散化/持有行为 |
| 季节性 | 周末 vs 工作日行为差异 | 插入机器人/传统金融的区别器 |

**这些特征中的每一个都不需要"因果解释"；它们仅仅是关于行为的事实。它们的集合是 D 的因子分析的输入。**

## 2. 第一层：因子分析

### 2.1 为什么用因子分析而不是 PCA？

- PCA 找到低维的超平面（线性投影在"成分"上），但不提供测量误差的解释
- 因子分析显式地假设有一个**潜在因子结构**生成观察到的特征——更适合 D 的目标（我们假设有少量潜在行为因子驱动观察到的特征）

### 2.2 因子数量的选择

- **Scree plot**：按降序绘制各特征值。查找"肘部"（从陡峭到平缓的转折点）来确定适当的因子数
- **平行分析**（Horn's procedure）：比较观察到的特征值与其在随机数据（相同维度的纯噪声）中预期特征值的百分比——如果观察到的第 k 个特征值小于在随机数据中的第 95 百分位值，选择 k-1 个因子

### 2.3 因子解释

对每个因子，观察高负载（|loading| > 0.5）的特征并提供一个实质性的标签。这类似于给 PCA 维度命名：

| 因子 | 解释为 |
|------|-------|
| 因子 A：（IF）| 高可扩展性和低分散性——"-类因子" |
| 因子 B：（IIF）| 高度不对称性 + 高 HF 弹性——"主动防御性" |
| 因子 C：（PLF）| 清算后最近的活动 / 空头恢复——"恢复" |

由此，D 产生了一个最小定义但有意义的"行为画像"（behavioral profile）。

## 3. 第二层：赛马

### 3.1 预测模型

| 模型 | 预测因子 | 含义 |
|------|---------|------|
| M0 | HF特征(min, mean, sd) + 抵押率 + 利用率 | 纯传统风险模型 |
| M1 | M0 + BDM五维度 | V4基线——"行为偏差的信用预测" |
| M2 | M0 + 从第一层提取的3-5个行为因子 | **主模型** |
| M3 | M0 + BDM + 因子 | 全模型 |

### 3.2 性能度量

- **主要**：AUC (ROC 曲线下面积)
- **辅助**：Brier分数 (预测概率的校准得如何)
- **时间序列交叉验证**：训练/测试按日历时间（例如，train on 2021, test on 2022），不是随机抽样

### 3.3 统计检验

- **DeLong 检验**：比较 M2 vs M0 的 AUC
- **似然比检验**：比较嵌套模型的拟合度 — M2 是否比 M0 在拟合上好得多？
- **Brier 评分差异**：M2 Brier − M0 Brier → 较小的值更好吗？——使用引导检验。

## 4. 第三层：治理模拟

### 4.1 设定

- 对于每个未在训练集中看到的 spell 月，预测其清算概率 $\hat{p}_i$
- 将用户分层为三个风险层：
  - 低风险: $\hat{p}_i < 0.05$
  - 中风险: $0.05 \leq \hat{p}_i < 0.15$
  - 高风险: $\hat{p}_i \geq 0.15$
- 对于高风险用户，模拟一个反事实：如果清算阈值从 HF = 1.0 提高到 HF = 1.05，坏账会发生什么？

### 4.2 福利计算

$$\Delta W = (B_0 - B_1) - (C_1 - C_0)$$

其中：
- $B_0$ = 真实的分摊的坏账 = Σ(坏账，当清算阈值 = 1.0 时发生的 dab)
- $B_1$ = 反事实的坏账 = Σ(坏账，当清算时阈值为 1.05 时)
- $C_0$ = 真实的分摊成本（被清算的用户在实地支付的分摊）
- $C_1$ = 反事实的分摊成本（更早被清算的用户支付的分摊）

### 4.3 推断

- Bootstrap resample 1000 个 spells，计算每次的 ΔW，然后找到其分布
- 如果 95% 置信区间 [2.5%, 97.5%] 完全在零以上 → ΔW > 0 是显著的 → 行为风险分层改善了福利

## 5. 稳健性

| 敏感性 | 主要方案 | 备选 |
|--------|---------|------|
| 特征集 | 30-50 个复合特征 | 仅 BDM 五维度 或 提取特征（最后的保险） |
| 样本 | 全样本 | 仅 EOA 用户（排除合约钱包） |
| 特征工程 | 平均值 ± 标准差 | 用 winsorized (按 1% 剪群) 版本 |
| 清算定义 | 任何清算事件 | 仅考虑"重大"的清算（UST > 500 美元） |
| 模型 | 逻辑回归 | LightGBM (如果术后的非线性信息在预测中有用) |

## 6. 与其他分支的比较

| 维度 | Branch D (数据驱动) | Branch A (RAT 轨迹) | Branch C (HAM 类型) |
|------|---------------------|---------------------|--------------------|
| 假设 | 最低限度 — 只要求行为有净信用 | 行为序列形态包含信息 | 存在不同的响应函数 |
| 复杂度 | 最低 — PCA + 逻辑回归 | 中等 — 序列 DTW + 层次聚类 | 中等 — 有限混合模型 |
| 可发表性 | 正/负结果都可发表 | 需要有足够多的活跃账户 | 需要识别到可解释的类型 |
| 期刊目标 | J. Financial Stability 或类似 | J. Econometrics | JEDC / Quantitative Finance |
| 博士论文角色 | 安全网——第二篇或第三篇论文 | 主线——方法论锚 | 第二线——行为解释 |

# 04_CVD-Credit — V3-3 信用真空度线

## 核心研究问题
在区块链金融场景中，用户对系统而言有多"不可见"？"信用真空度"（CVD）是否能够预测用户的外部风险表现？

## 关键构念
| 构念 | 描述 |
|------|------|
| **Credit Legibility** | 信用可读性/可见性——与信用度（creditworthiness）正交的概念 |
| **CVD** | Credit (Legibility) Vacuum Degree，信用真空度（或信用可见度缺口） |
| **D_id** | Identity Deficit：钱包→人的映射有多不确定 |
| **D_sem** | Semantic Deficit：链上活动多大程度缺乏商业含义标注 |
| **D_port** | Portability Deficit：信用信号在跨链/跨商户时有多不连贯 |
| **External Outcome** | 外部结果（黑名单、清算事件等）作为 CVD 的预测目标 |

## 核心理论支柱（B1-B4）
*从 V3 → V3.1 → V3-3 的演化*
- **B1**: 信息经济学（信息不对称/逆向选择）
- **B2**: 网络科学（网络拓扑中的传递性/流动性）
- **B3**: 宏观金融（系统性风险/关联性）
- **B4**: 信任拓扑学（去中心化系统中的信任结构）

## 导师会议后的定位
- V3-3 是"数据握在手里"才能做的研究
- 可以用来回应"如果拿不到私密数据"的 Plan A+ 场景
- 与"中间地带"的关系：中间地带回答了"应该披露什么"，CVD 回答了"我们现在能看到多少"

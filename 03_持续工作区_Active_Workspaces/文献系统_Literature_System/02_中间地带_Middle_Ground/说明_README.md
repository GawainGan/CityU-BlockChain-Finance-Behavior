# 02_Middle-Ground — 中间地带线

## 核心研究问题
在区块链金融场景中，是否存在一种"中间地带"机制——在**完全匿名**（无 KYC）与**完全透明**（传统银行式 KYC）之间，实现适度的信息披露？

## 关键构念
| 构念 | 描述 |
|------|------|
| Selective Disclosure | 选择性披露属性，而非全部身份信息 |
| Verifiable Credential | 可验证的数字凭证（W3C 标准） |
| Zero-Knowledge Proof | 零知识证明（证明陈述为真而不泄露陈述本身） |
| DID | Decentralized Identifier（去中心化标识符） |
| Privacy-Enhancing Credential | 隐私增强凭证（如 BBS+、CL 签名） |
| Minimum Disclosure | 最小化信息披露原则（GDPR 的数据最小化原则在链上的映射）|

## 导师会议指出的 gap
- 目前没有看到完全一致的已有研究
- 需要验证这个 gap 是真的空白，还是别人写过但不够好
- 核心：确认这是一个"全球性"问题，而非某类人群关注的特定问题

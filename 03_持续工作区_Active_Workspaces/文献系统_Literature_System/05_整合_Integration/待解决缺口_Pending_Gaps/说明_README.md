## 验证方法

每条 gap 采用"三步骤验证法"：
1. **paper_search 检索**：使用 2-3 组不同关键词组合在对应学科搜索
2. **引用追溯**：对已找到的近似文献追溯其引用网络
3. **结论记录**：确认为空白的，记录验证时间、结果和证据

# 理论设想 — Suggested Research Directions

此目录收录搜索过程中遇到的**有启发但无对应论文**的理论设想。每条记录仅包含：
1. 预想的原始来源（哪篇论文的哪部分提出了这个方向）
2. 简短的设想描述
3. 为什么该设想目前无对应文献

这与 `pending-gaps/` 的区别：
- `pending-gaps/`：已有文献或明确搜索方向，但尚未验证的空缺
- `suggested-research-directions/`：纯粹的未来想法，没有现成论文支撑

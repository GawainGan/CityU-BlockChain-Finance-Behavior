## 每个问题文件的结构

每个 `02_逐问题诊断与改进/` 下的文件包含以下结构：

1. **问题描述** — 一句话概括问题
2. **Report 1 原文** — 引用出问题的具体段落（保留原文）
3. **错误分析** — 为什么这是一个问题
4. **六层矩阵映射** — 引用对应的六层矩阵文件和层级
5. **修正方案** — 具体的修改建议
6. **文献支撑** — 引用 `04_文献/` 中的具体文献
7. **修改后的文本** — 可直接用于 Report v2 的修正文本


## 使用方法

### 向老师汇报时

1. 展示 `01_问题总表.md` — 概览所有问题和修正状态
2. 挑选 2-3 个关键问题展示 `02_逐问题诊断与改进/` 中的详细文件 — 展示诊断深度和修正质量
3. 强调：每个问题都有原文引用、错误分析、六层矩阵映射、文献支撑和修正文本

### 重写 Report v2 时

1. 按问题总表逐个处理
2. 每个问题参考对应的诊断文件中的"修改后的文本"
3. 将修改后的文本整合到 Report v2 的对应章节

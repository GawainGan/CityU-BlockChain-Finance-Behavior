## 文献使用原则

```text
Top Journal Literature
    → 决定理论语言
    → What should this construct mean?

Recent Working Papers
    → 决定研究竞争边界
    → What has already been done?
```

- QJE / JF / JFE / RFS / ReStud：用于定义经济机制
- SSRN / NBER / BIS / top-school working paper：用于确认当前前沿和直接竞争
- 两类缺一不可

## 时间梯度覆盖

每篇文献标注了 RECENCY 标签：
- ★newest / ≤6mo：最新（最高优先）
- ≤1y：最近一年
- ≤1.5y：最近一年半
- ≤2y：最近两年
- older：较早（仅用于基础理论）
